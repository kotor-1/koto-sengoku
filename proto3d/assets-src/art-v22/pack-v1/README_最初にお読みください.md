# こと戦国：人物・風景画像素材 第1版

## 内容
主要8人の人物画と、同じ絵から切り出した顔アイコンを収録しました。
徳川家康、本多忠勝、酒井忠次、石川数正、榊原康政、織田信長、浅井長政、朝倉義景です。
風景は軍議・城下町・大平原・森林・眺望・陣地など8点、地面の色素材は4点です。
人物画像には名前や枠を焼き込まず、名前はmanifestとファイル名で管理します。

## 必ず知っておいてほしい品質上の範囲
今回、画像生成は独立した高解像度素材ではなく、複数の絵をまとめたデザインシートを出力しました。
そのため、使う領域を個別に切り出して、人物は背景透過の処理を行っています。
主要人物の元の領域は幅203〜348pxで、風景は幅313〜522pxです。
通常名の人物・背景PNGは、見やすさと取り込み用に2倍補間した画像です。
細部が新しく生成されたわけではありません。`_native.png`には補間前の画像を入れています。

顔アイコンなど小さな表示での比較に使える第1版ですが、全画面の高精細背景や大きな立ち絵としては不足します。
前の依頼にあった「1024×1536で個別生成」「腰まで」「髭なし」「家紋なし」の条件には完全準拠していません。
衣装・年齢・装飾もゲーム用の創作デザインで、1570年の容貌や衣装を史実どおりに復元したものではありません。
元シートにあった人名・文字は正確さの根拠にはせず、個別ファイルから除外しました。
正しい人物名は、このパックのmanifestに記したものを使ってください。

## フォルダ
- `portraits/`：主要8人の背景透過PNG。通常名は2倍加工版、`_native`は元解像度。
- `faces/`：同じ人物画から切り出した256pxと128pxの透過顔アイコン。
- `backgrounds/`：場面用の背景画。通常名は2倍加工版、`_native`は元解像度。
- `textures/`：草・土・道・林床の512px PNG色画像。
- `web/`：公開容量を抑えるためのWebP版。使用前に配信可否を確認してください。
- `previews/`：人物・顔・風景・地面の一覧と、地面の2×2繰り返し確認画像。
- `source/`：切り抜き前の人物、加工前素材など。
- `docs/`：顔の切り出し座標、来歴、取り込み指示、条件確認。
- `gallery.html`：ブラウザで開けるローカル確認ページ。

## 使い分け
人物画と顔アイコンは同じ人物の絵から作っています。左右反転はしていません。
風景は物語・章の導入用の画像で、自由に歩ける3Dマップではありません。
大平原や森林の風景を、そのまま通行判定のある合戦地面へ貼らないでください。
地面には `textures/` の素材を使い、草・道・林の範囲はゲームの地形データで制御してください。
地面の向かい合う端の画素は合わせていますが、実ゲームでの縮尺・反復の目立ち方は未確認です。
色画像以外の法線・粗さ・高さデータは収録していません。

## 今回していないこと
