# 戦国RPG 自作主人公モデル 01

購入した素材・外注した素材は使わず、この会話のために作成した人物モデルです。
衣装は藍色の小袖と暗色の袴を基調にした、架空の若い武将のデザインです。
特定武将の肖像や史実衣装を正確に再現したものではありません。

## 入っているもの

- `assets/sengoku_hero.glb` — モデル、骨組み、材質、テクスチャ、待機・歩行・走行をまとめたファイル。
- `assets/sengoku_hero.gltf` と `.bin`、`assets/textures/` — 編集・差し替え向けの分離データ。同じ内容です。
- `assets/sengoku_hero.web.json` と `assets/textures/` — JSONファイルだけを置ける配信先用。内部モデルをbase64文字列として格納し、画像は外部ファイルです。
- `previews/` — 書き出したglTFから作った全身・近景・走行姿勢・背面の確認画像と動きの確認GIF。ゲーム画面のスクリーンショットや実機の録画ではありません。GIFは両クリップを同じ周期で比較するためのオフライン姿勢確認です。
- `source/build_hero.py` — 形状、衣服、材質、骨組み、アニメーションを編集・再生成するソース。
- `source/render_preview.py` — 同梱glTFを読み直して描画する確認用CPUレンダラー。
- `source/validate_asset.py` — 構造・配列・骨組み・アニメーションの確認用スクリプト。
- `integration/heroAsset.ts` — 既存Three.jsプロジェクトへ接続するコード例。既存ゲームへの組み込みは未確認です。
- `OPUSへの取り込み指示.txt` — 実装担当にそのまま渡せる短い作業指示。
- `asset-info.json` / `validation-report.json` — 実際の頂点数などと、確認範囲。

## モデルの仕様

Y軸が上、+Zが人物の正面、単位はメートルです。身長は髪の結び目まで約1.76mです。
20ジョイントのスキニング済みモデルで、衣服も骨組みに追従します。
アニメーションは `Idle` / `Walk` / `Run`。水平方向のルートモーションはありません。
移動は既存ゲーム側で行い、その実移動速度に合わせてクリップの再生速度を調整してください。
基準速度は Walk 1.4m/s、Run 3.0m/sです。

布の色テクスチャと細かな凹凸テクスチャは、このパッケージ用に生成しました。
市販のスキャン人物、既存ゲームから取り出したデータ、他者のモーションは含みません。
骨格数や名前が旧主人公と異なるため、旧モデル専用の骨角度書き込みは接続し直す必要があります。

## 配信上の注意

`web.json` 自体を通常のglTF JSONとして GLTFLoader に渡すことはできません。
中の `base64` を Uint8Array / ArrayBuffer に復号し、GLTFLoader.parse に渡します。
`integration/heroAsset.ts` に例があります。別ファイルの画像を置いた場所を resourceBase で指定できます。
モデルを `data:` URLでfetchする経路には戻しません。

現在のArtifactやGitHubリポジトリは、このパッケージの制作では変更していません。
本番へ置き換える前に、既存の画面と同条件で比較してください。

## 自作ソースから再生成

生成スクリプトは Python、NumPy、SciPy、Pillow を使います。

```bash
python source/build_hero.py
```

構造確認には、さらに trimesh が必要です。

```bash
python source/validate_asset.py
```

確認画像の再描画には、さらに numba が必要です。

```bash
python source/render_preview.py
```

外部モデル・画像のダウンロードは行いません。ゲームへの取り込みにPythonの実行は不要です。
必要なプログラムの依存パッケージはZIPには同梱していません。

## 確認した範囲と、まだ確認していない範囲

確認したこと：ファイル構造、データの範囲、正規化したスキンウェイト、法線、
アニメーションのループ端点、画像の読み込み、別のジオメトリ読込処理によるGLBの読込、
書き出したglTFからの静止画による形状と姿勢。
独自の検査であり、Khronosの公式適合性認証ではありません。

未確認：既存ゲームへの組み込み、Three.js上の実アニメーション再生、
iPhone / Android / Mac実機性能、任意の移動速度や姿勢切替での衣服の貫通。
この作業環境のブラウザではWebGL2コンテキストを作成できなかったため、
ブラウザ上で確認済みとはしていません。画像はCPUでオフライン描画しました。

布の物理シミュレーション、指ごとのアニメーション、表情、口の動きはありません。
顔や衣服の仕上げには改善余地があります。完成版の写実品質を認定した素材ではありません。
兵を大量に表示する用途の最適化は未実施です。まず主人公1人として比較してください。
