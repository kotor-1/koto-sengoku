# 制作元と利用について

制作日：2026-10-10。この会話でOpenAIの画像生成機能を用いて、一人または一場面ずつ新たに生成しました。
一覧ポスターからの切り抜きではありません。`characters_and_scenes.json`に生成IDと配役を記録しています。
原画と派生画像は`asset_manifest.json`のderived_fromで対応づけています。
外部の購入素材、俳優写真、他作品のキャラクター素材は本パックへ収録していません。
