# 依頼の原文：Version 22 の後の判断（地面 3 種・顔の表示・人物画と背景）

受け取った日：2026-10-09。前の公開：Version 22（版 ID 1791479988-143b、コミット 3fe5a7d）。

---

Version 22（3fe5a7d）の報告を受領しました。
3つの判断事項について、次の方針で進めてください。
現在の成果とセーブを維持し、同じ調査を繰り返さないでください。

【1. 草・土・道】

草・土・道の3種類を、操作できる比較版へ組み込んでください。
林床は不採用とし、現在の林の表示を残します。

「4枚そろわないと使えない」条件を、
素材ごとに採用・フォールバックできる仕組みへ変更してください。

草の模様4mは暫定値として、
通常の合戦倍率と拡大時の両方で確認します。
黄土色への変化で地形や兵が分かりにくくなる場合は、
該当する素材だけ旧表示へ戻せること。

地形の境界、通行、視界、合戦判定は変えません。
旧表示との比較方法は維持してください。

【2. 顔の表示】

戦場上の全名札を巨大化させないでください。
名札は名前・能力の印・押しやすさを優先します。

選択中の武将と能力の欄では、
48〜64px程度を初期値として顔を大きく見せてください。
実際の画面で、戦場や操作を圧迫しないサイズに調整します。
編成画面も、顔・名前・役割が認識できる配置にしてください。

スマホの台詞は、顔追加前の15px未満へ縮めないでください。
狭い画面では余白、顔の寸法、配置、送り方で対応し、
選択肢や本文を隠さないこと。

能力の点滅・ワンタップ発動・対象指定、
名札の優先表示・入力保護を維持してください。

【3. 人物画と背景】

今回見送った低解像度の人物画・背景は使いません。
一覧シートからの再切り出しや補間拡大で、
完成素材にしようとしないでください。

個別の新しい原画が届くまでは、
採用済みの顔アイコンと既存の背景を維持します。
不足する画像の代わりに、別の武将の絵を表示しないこと。

新しい原画の要件：
・人物：一人一枚、縦長、頭・髷・肩・腰まで切れない、
  文字・枠・家紋なし、透過加工可能。
・軍議背景：横長16:9、現行場面に合う昼の軍議所、
  人・文字・紋なし、人物と字幕用の余白あり。
・林床：真上の材質画像、強い木漏れ日や縞状の影なし。

画像生成環境や素材サイトへの再調査は不要です。
原画未着を理由に、地面3種とUIの改善まで止める必要はありません。

【4. 確認と提出】

今回は、
・通常倍率の大平原
・選択中の武将と能力の欄
・スマホの会話画面
の改修前後を、同じ条件で比較してください。

画像の読み込み失敗でも文字と操作が残ること、
画面外へはみ出さないこと、
合戦結果・保存・物語・音が変わらないことを、
変更の影響がある範囲で確認してください。

高解像度の立ち絵と背景が未実装であることは、
完了報告でも明確に分けてください。

旧版へ戻せる状態を残し、比較版を確認用URLへ反映してください。
新しい公開版の番号は、実際に公開された番号を報告してください。
