Version 19の報告を受領しました。
新しい機能や美術改修は追加せず、物語の説明を1点だけ補ってください。

【第二章Aの勝利後の撤収理由】
第一章で勝ったのに、第二章で織田勢が撤収する理由が
説明されていない点を修正してください。

実際のシナリオ・任務・対象部隊を確認し、
「どの部隊が」「なぜ撤収し」「家康が何を守るのか」を
短い字幕と情勢地図で分かるようにしてください。

局地戦の勝利と、その後の撤収を矛盾なくつなぐこと。
織田の本隊と援軍を混同しないこと。
敗北・撤退の経路に、勝利前提の説明を出さないこと。

必要な背景を補う場合は、ゲーム用の創作として記録してください。
史料にない出来事を、史実として断定しないでください。
既存の勝敗、兵力、支援、合戦条件は変えません。

【確認】
第二章Aの移行・出陣・帰還を、
スキップしない状態でつないで確認してください。
通常速度で確認できた範囲と、描画が遅く未確認の範囲を分けます。

修正の影響がある箇所を確認し、
旧版とセーブを保護して確認用URLへ反映してください。
全動画・全戦場の確認を無条件に最初から繰り返す必要はありません。

ここまでで止め、ユーザーの試遊結果を待ってください。
