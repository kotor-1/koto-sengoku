# 物語の見せ方と合戦間の RPG 部分（設計・実装の約束）

依頼本文：`docs/story-rpg-request.md`（正）。第一章：`docs/ieyasu1570-design.md`。第二章：`docs/chapter2-design.md`。史実と創作：`docs/ieyasu1570-history.md`。
ここは依頼本文を実装に落とした取り決めだけを書く。食い違うときは依頼本文が正。事前の調べ（コードの場所と制約）は作業者向けの資料にまとめた。

## 0. 守るもの

- 合戦（sim・ai・画面）・20 戦場・補充・確定した主目標・保存の決まりは変えない。演出・情勢画面・町・物見は、状態を読むだけで、兵・信頼・報酬・章の進行を変えない（物見の記録だけは状態に足す：§5）。
- 保存：2D・架空の章・演習のキーには触れない。第一章の保存は版 3 のまま（物見の記録が無ければ今と同じ文字列。あれば省ける欄 `scout` を足すだけ。旧版 Version 17/18 の読み込みは知らない欄を見ないので読める）。第二章は版 4 のまま（同じく省ける欄 `scout`）。視聴・スキップの印は保存しない。演出を軽くする設定だけは別のキー `koto-sengoku/3d-prefs` に、利用者が切り替えたときだけ書く。
- 史実：確認済みの背景（1570 年、織田・徳川の側と浅井・朝倉の側。忠勝は家康の家臣）と既存の分岐の文だけを使う。城・町の名前は出さない（「徳川の城下」）。地図は模式図と明記（位置・道・距離は正確ではない）。今ある文に出る地名（近江・三河・国境）より細かい地名を足さない。日付・逸話を足さない。
- 美術：顔・衣服・材質・建物の高精細化はしない。既存の素材（町家・城門・塀・木・人物 hero_v2・合戦の兵の形）を置き直し・使い回し、機能のための簡素な小物（荷車・俵・幕・柵・櫓・床几・筵）を形の組み合わせで足す。公開の容量（1 版 64MB。いま約 60.8MB）を超えない（新しい素材の読み込みは足さない）。
- 既存の確認との両立：町の今の人物の置き場所・開始の位置と向き・城門・道の真ん中（x −1.5〜2.5、z −12〜3）・城門への道すじは動かさない（本番の e2e が座標で歩く）。動く人々は当たり判定を持たず、この道すじに入らない。

## 1. 時間の進め方（このコンテナで通常速度を確かめるため）

- 演出の時計は実時間（performance.now）で進む（今の探索の 1 コマ 0.1 秒の上限に縛られない。1 コマの上限は 1 秒）。ページが隠れる・別のアプリへ切り替わる・ブラウザの窓が外れると自動で一時停止する。
- 演出の中身は「時刻 t の純粋な関数」（地図の旗・線・強調、字幕、3D の人と兵の位置、カメラ）。一時停止・スキップ・見直しは t を止める・終わりへ飛ばす・0 に戻すだけ。
- 地図の場面は不透明な層で、その間は 3D の描画を止める（軽い。地図の動きは毎秒 60 コマで出せる）。3D の場面（使者の到着・隊列の出発など）は 3D を描きながら、同じ時計で人と兵とカメラを動かす。
- このコンテナはソフトウェア描画で、町の 3D は毎秒 0.3〜0.9 コマ。3D の場面は「通常速度の時計で進むことと、その間のコマ」しか確かめられない（滑らかさは実機で未確認と報告する）。地図の場面は通常速度の動画で確かめられる。

## 2. 物語の演出（第一章の導入・第二章への移行・出陣・帰還）

演出は「データ」（状態から作る台本 `CineSpec`）と、それを再生する共通の再生器に分ける。ルートごとに別の動画は作らない。

| 演出 | いつ | 長さの目安 | 中身（状態から） |
|---|---|---|---|
| 第一章の導入 | タイトルの「はじめから」の後、城下に入る前 | 30〜45 秒 | 地図：1570 年・徳川の城下（三河）・織田と浅井・朝倉の対立（近江）・国境の浪人。3D：両家の使者が街道口から町へ入る・忠勝が待つ。字幕：誰が誰と組み、何を決めるのか（軍議で方針を選ぶ） |
| 第二章への移行 | 「第二章へ進む」→ 保存の後、結果確認の画面の前 | 30〜45 秒 | 地図：第一章の局地戦の場所と結果（勝敗の印）・協力と敵対の線（方針どおり）・約束の結果・今回の危機の場所（A 織田勢の退き口／B 浅井勢の孤立した丘／C 領内の村）。3D：帰還した兵と負傷兵（損害に合わせる）・援兵が着いていればその一隊・使者／村の使いの到着。字幕：誰を助け、何を守り、何を判断するか |
| 出陣 | 城門で「出陣する」→ 出陣前の保存の後、合戦の前 | 8〜15 秒 | 3D：城内で隊列が整い、城門から町を通って街道口へ（出陣する部隊の数・旗に合わせる）。地図：城下から戦場への矢印 |
| 帰還 | 合戦の結果の後（戦後の保存の後）、戦後の城下の前 | 8〜15 秒 | 3D：街道口から隊列が戻る（残った兵の数に合わせて減る。負傷兵を運ぶ・肩を貸す）。勝敗で旗の扱いが違う。地図：戦場から城下への矢印と結果の印 |

- 矛盾を避ける決まり（データの作り方で守り、テストで確かめる）：約束を破った・引き受けなかったのに感謝の場面を出さない／敵方の人物（A の長政、B の織田の武将・信長）を味方として出さない。信長は出さない／損害の大きい帰還を無傷に見せない（帰る兵の数は残った兵から、負傷兵は失った兵から）／援兵は第一章で `support.recovered > 0` のときだけ到着を見せる（0 なら約束の言葉だけ）／長政が負傷なら B の第二章に長政を出さない／C の第一章で守備隊は国境の砦にいて、城門から出陣しない／支援の部隊は戦場で加わる（城下から出ない）。
- 表示の数（隊列の人数・負傷兵の数）は見た目だけ（例：兵 50 で 1 人、上限あり）。保存の兵を増やしも減らしもしない。

## 3. 再生器（スキップ・一時停止・見直し・軽減）

- 専用の画面の層（種類 `cine`。会話の層とは別。メニューは開かない）。ボタン：一時停止／再開・字幕の前へ・次へ（場面の頭へ飛ぶ）・スキップ・動きを減らす。キー：Space／K で一時停止、←→ で場面、Esc でスキップ。ボタンは押し始めの守り（今の CHOICE_GUARD_MS）を使い、演出を始めたクリック・Enter・タップで飛ばない。背景を押しても飛ばない。
- 字幕：画面の下の不透明な帯。スマホ（844×390）で 16px 以上、2 行まで、話し手の名前は文字で。音は無い（無音で分かるように、場面の見出し「いつ・どこ」を地図の上に出す）。字幕は場面ごとに十分な時間（文字数 ÷ 8 秒と 2.5 秒の大きい方以上）。
- 動きを減らす：カメラを動かさず（決めた位置の静止した画）、地図は移動・拡大をせず、出てくる物は位置を変えずに現れる。利用者の設定（`koto-sengoku/3d-prefs`）か、端末の `prefers-reduced-motion`。
- 見直し：情勢画面の「演出を見直す」から、今の章の導入（第二章なら第二章への移行も）と、最後の出陣・帰還を見られる。見直しは状態を変えず、保存もしない。
- 演出中は探索の操作を止める（今の exclusive と同じ）。終わったら、主人公の位置・向き・カメラを始める前の物へ確実に戻す（城門の輪の中に戻さない）。演出の途中にタイトルへ戻る・再読み込みしても、保存の区切り（新しい遊び＝保存なし、第二章の始め・出陣前・戦後の保存）から続けられる。
- 偽の画面（テストの FakeView）や、演出の再生器が無い画面では、演出を飛ばして同じ進み方をする（待たない）。

## 4. 情勢の画面

- 探索（HUD の「情勢」ボタン・J キー）と軍議（「地図で見る」）から開く。閉じれば元の画面のまま（会話・選択は進まない）。
- 中身：模式図の地図（場所・旗・協力と敵対の線・今回の場所の強調）と短い説明：いつ・今いる所／協力している相手・敵対している相手／前の章の選択と結果（第二章）／今の危機／今回の目的（主目標の基本の説明。物見をしなくても分かる）／物見で記録したこと／演出を見直す。
- 関係は色だけでなく、記号と名前で区別する（例：◎ 徳＝自分、○ 織・浅＝協力、✕ 浅・朝・織・浪＝敵対、△＝敵対していない、？＝まだ分からない）。凡例を出す。
- 軍議の選択肢：軍議の画面の「地図で見る」で開くと、選択肢ごとのタブがあり、タブを押すとその方針・判断に関わる場所と進路を強調する。タブは見るだけで、方針・判断を決めない（閉じると軍議のまま。決めるのは今までどおり選択肢と確認）。
- 出さないもの：未発見の敵の正確な位置、まだ得ていない情報（合戦の前の説明でしか言っていない伏兵・援軍の出る所など）。

## 5. 小さな城下町と物見

町の場所（今の場所は動かさない。空いている所に足す）：

| 場所 | 置き場所 | 中身 |
|---|---|---|
| 城門（北）と城内 | 今の城門（z −12）。城内の東（x 9〜17、z −18〜−28）に軍議所 | 軍議所：陣幕で囲った所・床几（簡素な形）。奥に今ある御殿の素材。軍議の画面を開くとき、ここを短く映す |
| 町家の通り | 今の道と町家 3 棟＋南（z 11〜18）に町家の写し 1〜2 棟 | 荷車・俵・籠。荷を運ぶ人が歩く、店先で作業する人 |
| 街道口（南） | 道の南の端（z 15〜17）に木戸 | 出陣・帰還の隊列が通る。物見櫓の近く |
| 兵の詰所と負傷兵の休み場 | 東の囲い（x 8.2〜18、z −11.4〜3）。松の下。南東から入る | 小屋・槍立て・筵。負傷兵が休む（数は第一章の損害から）、出陣を待つ兵（支度の段階）、着いた援兵（援兵が戻ったとき） |
| 物見櫓 | 街道口の西（南西） | 物見（§5.2） |

### 5.1 町の人々（会話の相手とは別。話しかけられない・当たり判定なし・道すじに入らない）

- 状態から決める（純粋な関数 `ambientFor(状態)`）：負傷兵（第一章・第二章の損害が大きいほど多い。見た目だけ）・出陣を待つ兵（支度の段階）・援兵（`support.recovered > 0` の相手の旗）・荷を運ぶ人・店の人・門番。
- 歩く人は今の人物の素材（hero_v2 の写し。歩き・立ち・座りの動き）を 3〜4 人まで。兵の群れは合戦の兵の形（軽い）を使う。

### 5.2 物見（任意）

- 物見櫓の下で「物見」→ 高い所からの眺め（カメラを上げる。引きずって見回せる）→ 今の任務の方角の印（2〜3 か所）へ向いて「調べる」→ 記録が情勢の地図に入る。終わればもとの位置へ。
- 記録する中身は、今の任務の戦場の地形のデータ（道・丘・林・湿地・川・崖の切れ目・村の通り・安全地点など）から作る文と地図の印だけ。存在しない道・未発見の敵の位置は出さない（伏兵・援軍の出る所・敵の配置は出さない）。
- 記録は軍議（選択肢の説明に「物見：…」の 1 行）・合戦の前の説明（「物見で確かめた：…」の行）・情勢の地図に出る。主目標・確定した条件・補充の量と代償・兵・信頼は変えない。
- 任意。出陣の条件にしない。もう一度物見をしても記録は増えない（同じ中身）。
- 保存：第一章・第二章の保存の省ける欄 `scout`（記録した印の id の並び）。「はじめから」で消える（新しい遊びの状態に無い）。

## 6. つなぎ（コードの口。どれも省ける。架空の章は使わない）

- `Scenario`：`cinematic?(s, moment)`・`situation?(s, focus?)`・`ambient?(s)`・`scoutPoints?(s)`・`scout?(s, pointId)`。
- `GameView`：`cinematic?(spec)`・`situation?(view)`。`GameWorld`：`stage?(event, t)`・`setAmbient?(spec)`・`lookout?` 関係。無ければ飛ばす。
- 型は `proto3d/src/story/types.ts`（共通の約束）。

## 7. 確かめ

- 単体：台本・情勢・町の人々・物見の記録が状態から矛盾なく作られる（3 方針 × 第一章の結果 × 約束の組み合わせ）。視聴・スキップ・見直しで状態が変わらない。保存（`scout` の有無で版 3 の文字列・旧版の読み込み）。
- 画面（通常速度）：第一章の導入を通常速度で再生して動画に撮る（地図の場面は毎秒のコマで、3D の場面は時計どおりに進むことと、その間のコマ）。スキップ・一時停止・見直し・切り替え・再読み込み。物見を歩いて行う。第一章の結果が違う保存で、移行の演出と町の様子が変わる。既存の合戦・補充・保存・20 戦場の回帰。本番ビルド。
- 実機での滑らかさは未確認として報告する。
