## 1. 資料で確かめたこと（開始の情勢に使う）

| 事柄 | 出典 | ゲームでの使い方 |
|---|---|---|
| 姉川の戦いは元亀元年（1570年）。織田・徳川の側と、浅井・朝倉の側が戦った | 長浜城歴史博物館 | 開始の情勢：「1570年、織田と浅井・朝倉が敵味方に分かれている」。方針 A の敵味方 |
| 同館の「姉川合戦図」は江戸時代（19世紀）の制作で、合戦当時の実測図ではない | 長浜城歴史博物館 | 部隊の位置・人数・順序を史実として扱わない |
| 本多忠勝は、1560 年の初陣以降、家康の旗本 | 岡崎市観光協会 | 忠勝は、どの方針でも家康の家臣として味方 |

## 2. 判断が分かれる点・確かめていない点（事実として書かない）

| 事柄 | 扱い |
|---|---|
| 織田・徳川の同盟の成立年 | 台詞で年や経緯を述べない。「これまで共に動いてきた」までにとどめる |
| 浅井長政と織田信長の縁戚（婚姻） | 触れない |
| 1570 年春の浅井の離反の経緯 | 触れない。「織田と浅井は、いま敵味方に分かれている」だけ |
| 姉川での忠勝の単騎突入 | 伝承。今回の資料で裏付けがない。台詞・紹介に入れない |
| 忠勝が生涯負傷しなかったという話 | 伝承（岡崎市観光協会の記事が伝承として紹介）。事実として書かない。能力も無敵にしない。ゲームでは忠勝隊が崩れると負傷する |

## 3. ゲーム用の創作

| 創作したもの | 画面での示し方 |
|---|---|
| 会話と台詞のすべて（信長・長政の書状は、使者が趣旨を伝える形。実際の書状の引用ではない） | タイトル・高札・最初の会話に注記。書状の場面に「文面は創作」 |
| 方針 B（浅井と組む）と、その後の出来事 | 「史実から分かれた道」と明示。史実の家康が浅井側にいたとは書かない |
| 方針 C（自領の防衛）と浪人衆（架空の一団） | 両家への宣戦ではない。選ばなかった家が必ず敵になる形にしない |
| 戦場（「国境の原」の流用）・地形・兵数・配置 | 「1570年の情勢を背景にした架空の局地戦。姉川の戦いの再現ではない」 |
| 特殊能力 3 種（家康「立て直しの号令」・忠勝「退路の守護」・長政「盟友への援護」）と数値 | 「ゲーム用の創作。史実の人物の能力ではない」 |
| 戦前の約束（対象の退路を守る）と、信頼 ±25・援兵（兵 +150） | 会話の中で「約束と、その後の出来事は創作」 |
| 信頼・兵・損害の数値、戦後の出来事、6 つの結末 | 結末の記録に「会話・分岐・戦場・結末は創作」 |

- 家康が死ぬ結末と、一度の局地戦で家が滅ぶ結末は作らない（結末の文に「滅んだわけではない」「一度の負けで徳川の家が終わるわけではない」）。
- 他のゲーム・ドラマの台詞・人物紹介・能力値は使っていない。人物の見た目は既存の暫定素材のまま。
