# 3D 比較版：城門前の短い街路のビジュアル再設計（方針）

対象は「城門前の短い街路」1 か所。狭めるのはマップの広さだけで、人物・建物・植生・地面・材質・光・構図は一体で見直す。
承認された参考画像：`e2e-out/ref/ref_main.png`（生成された完成イメージ。ゲーム画面ではない）。
比べる元：コミット f280ee4 の開始画面（`e2e-out/deliver/start-2-after.png`）。

## 1. 全景の比較：印象の差が大きい順

測った値（1280 幅にそろえた画面全体）：

| | 参考画像 | 今の画面 |
|---|---|---|
| 明るさ p5 / p50 / p95 / p99 | 0.06 / 0.21 / 0.75 / 0.90 | 0.08 / 0.27 / 0.75 / 0.77 |

参考画像は暗い所がより暗く、明るい所がより明るく、色が濃い。今の画面は中間の明るさに固まり、特に地面が平ら。

### ① 構図と奥行き（最大の差）

- **参考画像**
  - 空間が斜めに奥へ抜け、層が重なる。
    - 左手前：町家の店先（2 階建て・深い軒・暖簾）が奥へ連なる
    - 中央：瓦を載せた塀が斜めに奥へ伸び、その奥に桜・松・大きな屋根
    - 右：巨大な門（屋根は画面上で切れる）、門越しに天守と木立
  - 地面は画面の下 1/3 強。
  - 主人公は大きく（画面の高さの 6 割、膝から上）、中央やや左。カメラは低く近い。
- **今の画面**
  - 塀をほぼ正面から見て、白い平面が画面中央を占める。
  - 門も正面から見ていて小さい。門越しは空の広場と平らな塀。
  - 主人公は全身が小さく入る。
- **目標**
  - カメラは主人公の約 2〜2.4 m 後ろ・肩の高さで、主人公が画面下半分を占める。
  - 門は右 1/3 で大きく。塀が斜めに奥へ。左は町家の店先。門越しの天守は大きく。
  - 手前・中景・遠景の 3 層を作る。

### ② 光と色

- **参考画像**
  - 低い午後の暖かい日差しが、長い影と強い明暗を作る。
  - 陰は深いが青みを帯び、形が読める。空は濃い青に雲。
  - 日の当たる縁（主人公の肩・袖、地面の凹凸）が明るく光る。
- **今の画面**
  - 日差しも空の光も中途半端で、全体が灰色がかる。
  - 陰は茶色い灰色で、空は白っぽく雲がない。
- **目標**
  - 日差しを強く・低く・暖かく。空の光（陰の色）は青く、弱く。
  - 物どうしが接する所・奥まった所の陰（AO）。空に雲。遠景の空気の青み。
  - 地面の湿った所だけ弱い照り返し（道全面を鏡にはしない）。

### ③ 人物

- **参考画像**：体つきが自然で、腕は体の脇に下がる。着物・袴は厚く重く垂れ、大きなしわと影がある。
- **今の画面**：腕が外へ開いた人形のような立ち姿。袴は細い筒。
- **目標**：人物全体を作り直す（今の主人公を土台として固定しない）。体の比率・立ち姿（待機で腕が下がる）・着物の量感と重さ。

### ④ 街並みと植生

- **参考画像**：左の町家は暗い木の柱・格子・深い瓦の庇・紺の大きな暖簾。桜は塀の奥に小さく、主に松と緑の木々。
- **今の画面**：手前の大きな桜が中央左を占める（花は粒の粗いピンクの点に見える）。町家は左端に少し見えるだけ。
- **目標**：配置を見直し、店先を画面に入れる。桜は塀の奥へ。緑の層を足す。

### ⑤ 地面と材質

- **参考画像**：日なたの土は明るく、凹凸・小石・轍が強い斜めの光で浮く。水たまり・湿った所は一部だけ。
- **今の画面**：地面は平らで暗い茶色。
- **目標**：日なたの土の明暗と凹凸を強く。湿った所は少しだけ、照り返しは弱く。

## 2. 進め方

1. **構図・配置と光**（同時に進める）
   - 配置：`scene.json`、`follow.ts` のカメラの距離・高さ、配置に合わせた素材の作り直し。
   - 光：`main.ts` の光と色、`scenery.ts` の空と雲。
2. **人物・建物・植生・地面**（1 の配置に合わせて作る）
3. **全体の見直し**：実際のゲーム画面で参考画像と並べて評価し、差が大きい所を直す。

- 評価は、実際のゲーム画面（人物・背景・光がそろった全景と、少し横を向いた画面）で行う。素材単体の改善やテストの合格は、全体の達成に数えない。
- 守ること：移動・走行・入力・読み込みの動作。エンジンは Three.js のまま。素材の購入・外注はしない。
- 生成画像や一枚絵の背景で代用しない。
- 細部の模様やしわを足すだけの修正は繰り返さない。
- 全マップ展開・合戦には進まない。
