# 依頼本文：物語の見せ方と、合戦間の RPG 部分の改修（Version 18 の次）

（ユーザーの依頼をそのまま保存。これが正）

Version 18をユーザーがテストプレイしました。
評価は「面白くなった。合戦はいい感じ」ですが、
合戦の間が人物との会話とテキスト送りだけで退屈で、
城下町としての体験も乏しく、状況を理解しにくいという指摘です。

次工程は「物語の見せ方と、合戦間のRPG部分」の改修です。
合戦システムや20戦場は作り直しません。

現在の最新版と作業状態を確認し、
既存の成果・セーブを保護して進めてください。

【1. 短い物語アニメーション】

動く情勢地図と、ゲーム内の3Dイベントを組み合わせ、
第一章の導入と、第二章への移行を分かりやすくしてください。

表示する内容：
・いつ、どこにいるか
・主人公が誰と協力しているか
・前章の選択と結果
・今回どこで何が起きているか
・誰を助ける、何を守る、何を判断するのか

地図上の旗・進路・強調表示と、
使者の到着、兵の準備、隊列の出発、帰還などを使います。
長文を自動で送るだけの演出にはしないでください。

章の導入は30〜45秒程度を初期目安とし、
出陣・帰還はさらに短くします。
既存の人物・兵士・町の素材を活用します。
顔のアップ、口パク、フルボイス、高品質な動画制作は必須にしません。

演出はセーブの実際の方針・勝敗・約束・支援状態に合わせてください。
約束を破ったのに感謝される、敵の人物が味方として現れる、
損害が大きいのに無傷で帰還する、といった矛盾を避けます。

新しい歴史上の出来事を無根拠に足さず、
確認済みの背景と、既存の分岐シナリオを使います。
地図が模式図の場合は、正確な城や部隊の実測配置とは扱わないでください。

【2. 情勢を見る画面】

探索と軍議から開ける、簡潔な情勢画面を用意します。

現在地、協力・敵対関係、前章の結果、
現在の危機、今回の目的を、地図と短い説明で見せてください。

軍議の選択肢と地図を対応させ、
選択肢を確認すると、関係する場所や進路が分かるようにします。
説明を確認する操作だけで、方針を確定しないこと。

演出をスキップしても、同じ必要情報をここで確認できること。
未発見の敵の正確な位置や、未入手の情報は公開しないでください。
色だけでなく、名前・記号でも関係を区別してください。

【3. 小さくても機能する城下町】

今の探索を、単なる会話相手のいる広場ではなく、
役割の違う場所がつながった小さな城下町にしてください。

必要な場所：
・城門と街道口
・町家と荷の行き来がある通り
・兵の詰所と負傷兵が休む場所
・軍議を行う場所

既存素材を再配置・再利用してください。
必要な機能用の簡素な小物は追加してよいですが、
顔、衣服、材質、建物の高精細化には戻らないでください。

NPCは少数でよく、歩く、荷の近くで作業する、
出陣を待つなど、場所に合う動きを付けます。
多数の会話NPCを追加するだけにしないでください。

第一章の損害や支援状態に応じて、
負傷兵、準備中の兵、到着した援兵などを出し分けます。
演出用の人数表示で、保存上の兵力を増減させないこと。

【4. 会話以外の行動を1件】

任意の「見張り地点での物見」を追加します。
主人公を操作して地点へ向かい、
現地を見回して調べると、
進路や要所の情報が情勢地図へ記録されるようにします。

得た情報は軍議や戦場説明と対応させ、
ただの収集数や報酬だけで終わらせないでください。
現在の任務に対応する地形情報を使い、
存在しない道や、未発見の敵の正確な位置を捏造しないこと。

この行動は必須にしません。
主目標の基本説明は、物見をしなくても分かるようにします。
毎回同じ町歩きや、全NPCへの会話を出陣条件にしないでください。

現在の補充判断は兵の様子とつなげて見せますが、
補充量、代償、固定済みの主目標を演出の都合で変更しないこと。

【5. スキップ・中断・保存】

演出にはスキップ、一時停止、後から見直す方法を付けます。
字幕はスマホでも読める大きさにし、無音でも理解できること。
激しいカメラ移動は避け、演出を軽減する表示も用意します。

視聴、スキップ、再視聴によって、
兵力・信頼・報酬・章の進行が変わらないようにしてください。
同じ選択と同じ開始状態なら、同じゲーム状態へ戻ること。

演出をスキップしても、未決定の選択肢は勝手に決めないこと。
演出中の入力が、探索の移動や選択確定へ漏れないこと。
終了後は通常カメラと操作へ確実に戻すこと。
アプリ切り替えや再読み込み後にも進行不能にならないこと。

保存は安全な場面の区切りで行い、
演出フレームごとの保存は不要です。
演出を再生しただけで、補充や戦後処理を再実行しないこと。

【6. 作業範囲】

第一章の導入と、第二章の3方針に組み込みます。
共通の演出をデータで出し分け、
ルートごとに別の巨大な動画を作る必要はありません。

第三章、新しい合戦場、経済システム、装備収集、
美術の大規模改修、素材購入、外注、エンジン変更は行いません。

既存の資料や仕様を引き継ぎ、
新しい方針書や撮影道具の作成だけで作業を止めないでください。

【7. 完成確認と公開】

通常速度で章の導入を見て、
「誰がどこで困り、自分は何を判断するのか」が理解できること。
町を実際に歩け、会話以外の物見を任意に行えること。
第一章の結果で、演出と町の様子が変わること。
スキップした場合も、同じ情報と正しい進行が得られること。
既存の合戦、補充、保存、20戦場を壊していないこと。

アニメーション自体の確認は、
静止画や一コマずつ進めた画像だけで完了扱いにしないでください。
通常速度で確認できた環境と、未確認の実機を区別してください。

必要な確認後、旧版へ戻せる状態を残して確認URLへ反映します。
美術の静止画承認待ちだけでは公開を止めないでください。

報告は、
公開版とコミット、追加した演出、町でできる行動、
第一章の結果の反映例、確認結果、未確認事項に絞ってください。
