# 第二章の確認の記録

依頼本文 `docs/chapter2-request.md` §8・設計 `docs/chapter2-design.md` §9 の確認の記録。再起動の後は、この表を見て、同じコミットで済んだ項目は飛ばし、「未」の項目から再開する。
作業は 3 つの担当に分かれている（キャンペーン＝章のつなぎ・状態・保存・会話・画面／合戦＝編成・釣り合い・合戦の画面の言葉／判断待ち＝e2e と field テストの直し）。各担当が自分の節に書く。

- **確かめ方の種類：**
  - 本物の入力＝画面のクリック・タップ・キー（待ちだけ早送りのものはそう書く）
  - 早送り＝台本の命令・合戦の時間を早送りで進める
  - 直接操作（直接状態変更）＝状態・保存を直接作る・書き換えてから確かめる（偽の画面のテスト・開発用の `__game.setIeyasu2Phase`・`__game.talk`・保存の文字列を入れる、を含む）
  - 実機＝実際の端末での確認（ここでは **していない**。コンテナはソフトウェア描画）
