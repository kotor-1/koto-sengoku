### 3. 人物と建物の 3D 素材を何から用意するか

- 外部の素材サイトは、この作業環境のネットワークの決まりで使えなかった（接続を拒否：Poly Haven、Kenney、Quaternius、OpenGameArt、Sketchfab、Mixamo）。通るのは npm と GitHub の生ファイルだけ。
- GitHub の glTF 見本（Khronos の CesiumMan など）は、現代の西洋風の人物・機械で、和風のセミリアルに合わない。**利用条件が明確で、和風の人物・建物として使える外部素材は、ここでは用意できなかった。**
- そこで今回は、**人物・建物・木をすべてこの試作のコードで 3D の形として作った**（`proto3d/src/assets/`）。2D の画像を板に貼ったものではない。
  - 作った形は GLB（glTF）に書き出し（`npm run proto3d:models`）、ゲームは GLTFLoader で読み込む。**外部で作ったモデルに替えるときも、同じ名前の GLB を置けば読み込める**（読み込みの仕組みは本物の素材と同じ）。
- 無断の購入、利用条件が分からない素材の採用はしていない。

| 素材 | 作り手・出どころ | 利用条件 |

| 求められたこと | 実装 |
|---|---|
| 城門 1 つ | 高麗門（鏡柱・冠木・切妻の瓦屋根・控柱と小屋根・内側へ開いた門扉と鉄の金具）と左右の土塀（石積み・漆喰・狭間・瓦の笠） |
| 民家 1 軒 | 町家（弁柄の格子・暖簾の入口・犬矢来・虫籠窓・真壁の柱と梁・庇・切妻の瓦屋根・縁台） |
| 木 | 黒松 1 本（うろこ状の樹皮、段になった葉）と広葉樹 1 本 |
| 道 | 城門をくぐって続く土の道、縁の小石、草むら |
| 主人公 1 人 | 若殿（藍の小袖・縞の袴・腰紐・大小・足袋と草履・茶筅髷）。骨組みで動く 3D の形 |
| 歩く・止まる・向きを変える | 待機と動きを速さで混ぜる。入力した方向へすぐ進み、体の向きは進みながら約 0.3 秒で向き直る（向き終わるのを待たない）。逆向きに切り返したときだけ、一度だけ速さを 4 割に落として勢いを殺す |
| 建物の横を通れる | 町家の北側の路地を通って裏まで抜けられる。家・土塀・門の柱・木の幹には当たり判定（壁に沿って滑る） |

| 操作の向き | 上を押すと画面の上（北）、右を押すと画面の右（東）へ進む。キーボードとスティックは同じ入力（画面の向き）として扱い、地面の方向への変換は `proto3d/src/game/motion.ts` の `screenToGround` で 1 回だけ行う。カメラの向き（`CAMERA_YAW`）はカメラの置き方と変換で共用する |
| 隠れたとき | 主人公が建物・木の裏に入ってカメラから隠れると、その建物・木を半透明にする（2D 版と同じ考え）。固定カメラでは、家の北側の路地を歩くと家の屋根に隠れるため |
| 操作 | キーボード（矢印・WASD）、スマホは画面左側のスティック。フォーカスが外れたら・画面を離れたら（アプリの切り替えを含む）移動の入力と Shift を解除（戻っても勝手に動かない） |
| 歩く／走る | 右下のボタン（タップ・クリック）で切り替える。押し続けなくてよい。スマホではスティックを動かしながら別の指で押せる。PC は Shift を押している間だけ走り、離すとボタンで選んだ方に戻る。スタミナ・待ち時間はない |
| 速さ | `proto3d/src/game/motion.ts` の `SPEED` だけで調整する（歩き 1.55m/秒＝これまでと同じ、走り＝歩きの 2.2 倍の 3.41m/秒）。ゲーム全体の時間は変えず、主人公の上限の速さだけを変える。走るのをやめると歩きの速さまでなめらかに落とし、入力を離すと走りからでも 0.3 秒で止まる。斜めでも速くならない。1 回に 0.1m より長く動くときは分けて当たり判定をする（画面が重くても壁・柱をすり抜けない） |
| 歩き・走りの足運び | 動きは式から作り、骨組みで足の接地を計算して整える（`proto3d/src/assets/hero.ts`）。接地している足の裏を地面に着け、振り出す足は地面に擦らないよう膝を曲げる。走りは、接地の間の足首を一定の速さで後ろへ送る置き場所から太もも・膝を求める（足が滑らない）。左右を入れ替える間に両足が浮く（腰の上下は約 4cm）。上体は少し前傾、肘を曲げて腕を振る。歩きと走りは位相をそろえ、進んだ距離から再生位置を決めるので、切り替えや止まる途中でも足が地面の上で滑らない。止まると脚も止まり、待機の姿へ戻る |
| 光 | 日差し（影）・空と地面の照り返し・やわらかい映り込み（画質「低」では省く）・薄い霧 |

## 未完成の部分（今回の範囲で足りないもの）

- **見た目の水準**：目標は「落ち着いた和風のセミリアル」だが、手続きで作った形なので、**セミリアルの水準には届いていない**。整った 3D の模型に近い見た目。
  - 人物：顔は頭の形に描いた絵で、目・鼻・口の立体はない。手の指は分かれていない。服のしわ・布の揺れ（物理）はない。近づくと作りの粗さが分かる（通常のカメラの距離では目立ちにくい）。
  - 建物：瓦・柱・格子は形で作ったが、汚れ・風化・木目の割れなどの細かい質感は少ない。内部はない（入口の奥は暗い面）。
  - 木：葉は絵を貼った小さな板の集まり。
- 走りは式から作った簡易な動きで、本格的な走行アニメーション（モーションキャプチャや手作業の調整）ではない。
  - 袴・袖・髪は体の骨に付いて曲がるだけで、揺れ・はためき（布の物理）はない。膝を大きく畳むと、幅の広い袴が脚の形に沿って曲がり、硬く見える。
  - 走り出し・止まり・急な切り返しの専用の動きはない（歩き・走り・待機を速さで混ぜる）。
  - 骨組みの計算では、接地した足の送りのむらは走りで約 0.01m/秒。歩きは、かかとが着く一瞬（約 0.05 秒）に最大 0.45m/秒のずれがあり、それ以外は設計速度の ±15% ほど。
- 走り以外の動き（話す・振り向きの専用の動き）はない。
- 会話・保存・メニュー・時間帯・天候・NPC などは入れていない（今回は作らない範囲）。
- 2D 版との混在（Phaser と Three.js を同じ画面で使う）は作っていない。
