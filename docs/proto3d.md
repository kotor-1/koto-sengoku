### 3. 人物と建物の 3D 素材を何から用意するか

- 外部の素材サイトは、この作業環境のネットワークの決まりで使えなかった（接続を拒否：Poly Haven、Kenney、Quaternius、OpenGameArt、Sketchfab、Mixamo）。通るのは npm と GitHub の生ファイルだけ。
- GitHub の glTF 見本（Khronos の CesiumMan など）は、現代の西洋風の人物・機械で、和風のセミリアルに合わない。**利用条件が明確で、和風の人物・建物として使える外部素材は、ここでは用意できなかった。**
- そこで今回は、**人物・建物・木をすべてこの試作のコードで 3D の形として作った**（`proto3d/src/assets/`）。2D の画像を板に貼ったものではない。
  - 作った形は GLB（glTF）に書き出し（`npm run proto3d:models`）、ゲームは GLTFLoader で読み込む。**外部で作ったモデルに替えるときも、同じ名前の GLB を置けば読み込める**（読み込みの仕組みは本物の素材と同じ）。
- 無断の購入、利用条件が分からない素材の採用はしていない。

### 4. 素材の利用条件と、歩行の動き

| 素材 | 作り手・出どころ | 利用条件 |

| 歩き・待機の動き | この試作のコード（`proto3d/src/assets/hero.ts`、式から作ったキーフレーム） | 同上 |

- 必要な動き：**歩き**（必須）と**待機**。どちらも外部から用意できなかったので、骨組み（18 本の骨）を動かす式から作った。モーションキャプチャではない。

  - 木：葉は絵を貼った小さな板の集まり。
- 歩き以外の動き（走る・話す・振り向きの専用の動き）はない。
- 会話・保存・メニュー・時間帯・天候・NPC などは入れていない（今回は作らない範囲）。
- 2D 版との混在（Phaser と Three.js を同じ画面で使う）は作っていない。
