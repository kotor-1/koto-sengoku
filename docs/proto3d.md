### 3. 人物と建物の 3D 素材を何から用意するか

- 外部の素材サイトは、この作業環境のネットワークの決まりで使えなかった（接続を拒否：Poly Haven、Kenney、Quaternius、OpenGameArt、Sketchfab、Mixamo）。通るのは npm と GitHub の生ファイルだけ。
- GitHub の glTF 見本（Khronos の CesiumMan など）は、現代の西洋風の人物・機械で、和風のセミリアルに合わない。**利用条件が明確で、和風の人物・建物として使える外部素材は、ここでは用意できなかった。**
- そこで今回は、**人物・建物・木をすべてこの試作のコードで 3D の形として作った**（`proto3d/src/assets/`）。2D の画像を板に貼ったものではない。
  - 作った形は GLB（glTF）に書き出し（`npm run proto3d:models`）、ゲームは GLTFLoader で読み込む。**外部で作ったモデルに替えるときも、同じ名前の GLB を置けば読み込める**（読み込みの仕組みは本物の素材と同じ）。
- 無断の購入、利用条件が分からない素材の採用はしていない。

### 主人公の自作モデル 第 2 版

利用者が用意した第 1 版（`proto3d/assets-src/hero_v1/`、受け取ったまま保存）の生成用ソースを写し、背中から近くで見える所を直した（`proto3d/assets-src/hero_v2/build_hero.py`。Python・NumPy・SciPy・Pillow で `hero_v2.glb` を作る）。骨組み・動き（Idle / Walk / Run）は第 1 版と同じ。

- 首の後ろを回る襟と、その上に少しのぞく白い半襟を足した（第 1 版は背中の首元が開いて見えた）
- 首から肩の付け根の肌が、背中で小袖の外へ突き出していたのを内側に収めた
- 袴の腰板（背中の腰の台形の板）と縁を足した
- 袴の色を少し明るく暖かい灰茶にし、細い縦縞を入れた（黒い塊に見えないように）
- 袖のふくらみを少し小さくした

## 未完成の部分（今回の範囲で足りないもの）

- **見た目の水準**：目標は「落ち着いた和風のセミリアル」だが、手続きで作った形なので、**セミリアルの水準には届いていない**。整った 3D の模型に近い見た目。
  - 人物：顔は頭の形に描いた絵で、目・鼻・口の立体はない。手の指は分かれていない。服のしわ・布の揺れ（物理）はない。近づくと作りの粗さが分かる（通常のカメラの距離では目立ちにくい）。
  - 建物：瓦・柱・格子は形で作ったが、汚れ・風化・木目の割れなどの細かい質感は少ない。内部はない（入口の奥は暗い面）。
  - 木：葉は絵を貼った小さな板の集まり。
- 走りは式から作った簡易な動きで、本格的な走行アニメーション（モーションキャプチャや手作業の調整）ではない。
  - 袴・袖・髪は体の骨に付いて曲がるだけで、揺れ・はためき（布の物理）はない。膝を大きく畳むと、幅の広い袴が脚の形に沿って曲がり、硬く見える。
  - 走り出し・止まり・急な切り返しの専用の動きはない（歩き・走り・待機を速さで混ぜる）。
  - 骨組みの計算では、接地した足の送りのむらは走りで約 0.01m/秒。歩きは、かかとが着く一瞬（約 0.05 秒）に最大 0.45m/秒のずれがあり、それ以外は設計速度の ±15% ほど。
- 走り以外の動き（話す・振り向きの専用の動き）はない。
- 会話・保存・メニュー・時間帯・天候・NPC などは入れていない（今回は作らない範囲）。
- 2D 版との混在（Phaser と Three.js を同じ画面で使う）は作っていない。

## 参考画像（承認されたアート方向）との差
