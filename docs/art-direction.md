# アート方向（2.5D ビジュアル試作）

目的：完成アートではなく、「現代的な 2.5D 戦国 RPG」としてこの方向に進む価値があるかを判断できる見本を作る。

## 目指す見た目

- 斜め上から見下ろす視点。地面は平ら、立っている物（家・木・壁・人物）は高さを持って上に伸びる。
- 高解像度の 2D。**ドット絵にしない**（ギザギザの輪郭、1 色ベタ塗りの四角、16bit 風の配色は避ける）。
- 光と影：左上やや手前から差す光。面の明暗、柔らかい楕円の影、右（東）へ伸びる影。
- 落ち着いた戦国の色調：くすんだ緑・土色・漆喰の白・墨色の瓦・藍。朱や金は差し色だけ。純黒・純白は使わない。
- デフォルメしすぎない。人物は約 6 頭身の「落ち着いた等身」。

## 判定基準

**スマホで画面を見たとき、昔の 2D ブラウザゲームではなく、現代的な戦国 2.5D RPG に見えるか。**
効果（光・粒子・煙・ぼかし）の量ではなく、人物・建物・地面そのものの質を優先する。
素材が古く見えるのを効果で隠さない。

## 全体で統一すること（担当ごとに絵柄を変えない）

| 項目 | 統一ルール |
|---|---|
| 頭身 | 人物は約 6 頭身（身長 ≈ 34 ワールド px、頭 ≈ 5.5〜6 px）。デフォルメしすぎない |
| 輪郭線 | 「あり・細い・色つき」。ワールド 0.3 px 前後（tex=4 で約 1〜1.5 Canvas px）。黒ではなく、その部分の色を暗く・少し彩度を落とした色。建物・木・人物で同じ考え方 |
| 陰影 | 3 段階程度（明部 +12〜15%、中間、影 −25〜30%）。影の境目はやわらかいグラデーション。光沢の強いハイライトは使わない |
| 色の鮮やかさ | PALETTE の彩度を上限とする。原色・蛍光色は使わない。差し色（朱・金）は小面積だけ |
| 光源 | すべて左上やや手前から（`LIGHT_DIR`）。上面・左面が明るく、右・下が暗い。影は右やや上（`SHADOW_DIR`） |
| 解像感 | すべて「高解像度の 2D 絵」。1 ワールド px 単位の段差・ディザ・ベタ塗りの四角は禁止。細部の線は 0.3〜0.6 ワールド px |
| スケール | タイル 16 px ≒ 1 m。人物 34 px ≒ 1.7 m。民家の軒の高さ（前面の壁 30 px）≒ 2 m 強、城壁の前面 20 px + 瓦。扉や窓の大きさを人物に合わせる |
| UI | 角丸 10〜14 px（ボタンは丸・ピル型）、背景は暗色の半透明（不透明度 0.55〜0.75）、細い 1 px の明るい縁（不透明度 0.1〜0.15）、余白は広め（12〜16 px）。太い枠・レトロ風フォントは使わない |

## UI の方針

- 探索画面では世界を広く見せる。常に表示するのは最小限（目的の小さな表示、メニュー・時間帯の小さな丸ボタン程度）。
- スマホの操作：移動スティックは触れるまで目立たせない（薄い案内のみ）。**アクションボタンは、話せる・調べられる相手に近づいたとき、または会話中だけ表示する**（「話す」「調べる」「次へ」）。常時表示の大きな四角ボタン群は作らない。
- 近づいた対象の頭上には小さな印（吹き出し）を出す。
- 会話枠は画面下部に、半透明で余白を広く、読みやすい文字で。

## 技術上の約束

| 項目 | 内容 |
|---|---|
| 座標 | core と同じ（1 タイル = 16 ワールド px）。当たり判定・移動は変えない |
| 解像度 | 物・人物は ワールド px × 4（低品質時 3）、地面は × 2（低品質時 1.5）の Canvas に描き、縮小表示 |
| 基準点 | 物の「地面に接する点」。描画順（前後）はこの点の Y で決まる |
| 光 | `LIGHT_DIR`（左上手前から）。影の向きは `SHADOW_DIR`（右やや上） |
| 色 | `src/render/art/spec.ts` の `PALETTE` を基本に使う |
| 素材 | 画像ファイルは使わず Canvas 2D で描く（有料素材なし）。`ctx.filter` は Safari の古い版で効かないので使わない。ぼかしはグラデーションか `shadowBlur` で |
| 乱数 | seed つき（`rng()` / `hash2()`）。毎回同じ絵になること |

大きさ・基準点・キー名は `src/render/art/spec.ts` と各モジュールの export が正。WorldScene はそれに従って置く。

## モジュールと担当範囲

| ファイル | 内容 |
|---|---|
| `art/character.ts` | 主人公・家臣。8 方向 × 待機＋歩行 8 コマ（家臣は待機のみ） |
| `art/buildings.ts` | 民家 3 種と影、城壁、城門、天守と影、橋、小物（井戸・高札・道標・柵・関所の柵） |
| `art/nature.ts` | 木 3 種と影、草むら 3 種、花 2 種 |
| `art/ground.ts` | マップ全体の地面を 1 枚に焼く（草地・土の道・石畳・水面の下地・田・城門の床） |
| `art/fx.ts` | 影・煙・粒子・灯り・周辺減光・水面のきらめき・地面の質感・吹き出し・日差し |

## 本番素材に置き換えるとき

各モジュールの export（キー名・大きさ・基準点）を保ったまま、Canvas で描く代わりに画像を読み込めば、WorldScene は変えずに済む。
