【1. 補充と主目標】

補充によって「兵が少ない場合の主目標」が外れ、
自動的に厳しい目標へ変わる方式は修正します。

第二章へ移行するときに第一章の結果を記録し、
第二章の任務・方針を選んだ時点で、
その結果を基準に主目標条件を確定してください。

その後の補充、保存、再読み込みで、
主目標を勝手に再計算しないでください。
任務・方針を明示的に変更する場合は別として扱います。

補充を待つ代償がある場合は、選択前に説明してください。
このために新しい経済・兵站システムは作りません。

比較では損害率だけでなく、
出陣兵数、損失人数、残存兵数、所要時間、副目標を記録してください。
補充したらどんな作戦でも必ず有利になるよう、
結果を強制する必要はありません。

【2. 開始直後の全軍撤退】

既定の撤収対象が実際に退き口から離脱し、
主目標を満たした結果の勝利なら、その作戦を残してください。

命令を押しただけで即勝利したり、
主目標に含まれる撤収対象を置き去りにして勝利したりする場合だけ、
判定を修正してください。

副目標や約束の未達成は、主目標の勝利と分けて記録します。

即時撤退を禁止するためだけの最低戦闘時間、
強制交戦、新しい敵増援は追加しないでください。
損害や副目標に代償があるなら、有効な作戦の一つとして扱います。

【3. 残りの確認】

現在の成果を引き継ぎ、
3方針それぞれで第一章の開始から第二章の区切りまで、
画面操作で通してください。

保存直接投入による確認とは区別し、
早送りや探索描画の省略があれば、その範囲を明記してください。

補充前後・第二章への移行・戦後の再読み込みで、
目標条件が変わらず、補充や支援が二重適用されないことを確認します。

全組み合わせを長時間のブラウザ確認にする必要はありません。
残りは既存の単体テストや台本による確認を使ってください。

判断待ちだったテスト修正も既存作業を引き継ぎ、
終わっている調査・仕様書・素材制作を繰り返さないでください。

必要な確認を終えたら、旧版とセーブを保護して公開してください。
報告は公開版番号・コミット・第二章への進み方・
確認結果・未確認事項に絞ってください。
