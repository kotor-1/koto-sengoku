# 依頼本文：第3群5戦場（合計15戦場）と先に整える操作（Version 15 の次）

（ユーザーの依頼をそのまま保存。これが正）

Version 15（コミット14e407e）の報告を受領しました。
現在の10戦場・軍勢表示・能力・歴史シナリオを維持し、
第3群の5戦場を追加して、合計15戦場へ進めてください。

最低20種類という完成要件は継続します。
今回は11〜15を実装し、残り5種類は次工程とします。

現在さらに作業が進んでいる場合は、
過去のコミットへ無断で巻き戻さず、成果を確認して引き継いでください。

【重要：戦場の面白さ】

「正面突破は必ず負け、指定された迂回だけが正解」
という設計にはしないでください。

地形を無視した無計画な攻撃と、
兵種・予備隊・能力を使って準備した正面攻撃は区別します。

損害、所要時間、副目標、守れる部隊などに違いが出る、
複数の作戦を成立させてください。

すべての戦場ですべての作戦を同程度に強くする必要はありません。
ただし、自動テストも「正面なら必ず負ける」こと自体を
合格条件にしないでください。

【先に整える操作】

1. 移動先に味方がいる場合
通常の選択操作と、移動先指定を区別できるようにする。

必要時に使える「移動先指定」モードでは、
味方の近くを押しても部隊を選び直さず、
その場所または付近の通行可能地点への移動を命じる。

既存の地面クリックによる移動は残す。
すべての移動に追加操作を強制しない。

能力対象の指定中は能力の選択を優先し、
同じ入力が移動命令へ漏れないようにする。

2. 目標・地形説明・知らせ
スマホで部隊名札や能力の印を隠す場合は、
説明を畳む、表示位置を調整するなど必要最小限で改善する。
操作不要の表示がタップを奪わないこと。

3. 家康の号令
自隊を含めて実際に効果を与えられる対象がいるかを確認する。
誰にも効果を与えられない場合は、
発動可能の点滅をせず、使用回数も消費しない。

士気回復だけでなく敗走防止も有効な効果として判断する。
自隊が効果対象に含まれる仕様なら、そのことを説明する。

榊原の士気低下や、号令終了後の危険を
今回まとめて軽減することはしない。

【追加する5戦場】

11. 湿地
主目標：指定数の戦闘可能な部隊を出口へ突破させる。

土手道、乾いた足場、移動の遅い湿地を作る。
安全な道への集中と、湿地を使う迂回で、
時間と損害の違いを出す。
既存の水田の色替えだけにはしない。

12. 村落
主目標：村内の重要地点を一定時間守る。

家屋、柵、複数の通りで戦線を分ける。
主力の配置と予備隊の移動が重要な戦場にする。
建物は通行や射線に実際に影響させる。

13. 寺社周辺
主目標：二つの要所を同時に、指定時間確保する。

正面の石段、脇道、林側の入口を用意する。
一方へ集中するだけでは他方が手薄になる構成にする。
宗教施設だから魔法的な効果が出る仕組みにはしない。
地形・入口・高低差を使った架空の戦場として扱う。

14. 城下町外縁
主目標：複数の出口へ向かう敵の突破を一定数以内に抑える。

大通り、脇道、門口を用意し、
敵の進路を見て守備を組み替える戦いにする。
突破数と、敗北までの残り許容数を表示する。
兵の集団を部隊単位で判定し、表示人数で判定しない。

15. 城攻め前面
主目標：外門の制圧 → 最初の曲輪の確保。

城全体や天守内部は作らない。
外門と守備側の射撃拠点・側面拠点を組み合わせる。
門を閉鎖中は通れず、制圧後は通れること。
通行状態の変更後に、経路も正しく更新されること。

城壁破壊の物理表現、梯子、攻城兵器は今回は不要。
門の制圧条件は、画面で明確に説明する。

【共通の設計】

既存の戦場データ構造を利用する。
新しいルールは、地点防衛、突破数、段階目標、
通行・射線を遮る障害物などの共通機能として実装する。
戦場名ごとの条件分岐を大量に増やさない。

地形、入口、初期配置、目標が異なる5戦場を作る。
背景の色や名前だけを変えたコピーは数に含めない。

主目標、副目標、約束、勝敗は別に記録する。
演習の結果を、歴史シナリオの人物関係へ勝手に反映しない。

味方・敵の部隊数は現在の上限内に収める。
増援も、同時に存在する部隊数に含めて検査する。

大軍表示、LOD、武将能力、点滅と直接発動は維持する。
必要な合戦用の簡略建物は追加してよいが、
探索の人物や街の美術改修は再開しない。

【確認】

15戦場すべてを、通常操作で選んで開始できること。
新しい5戦場では、画面操作で命令し、
それぞれ少なくとも一つの作戦で主目標まで到達すること。

複数の作戦の違いは、台本による比較も使ってよいが、
通常操作、早送り、直接状態変更を区別して報告する。

門・建物・狭い道での詰まり、
射線、名札と目標表示の重なり、
能力発動と移動命令の競合を確認する。

既存10戦場、歴史シナリオ、架空シナリオ、
保存と二重適用防止を壊さないこと。

確認は固定したビルドで行い、
再起動後は記録を確認して未完了・影響ありの項目から再開する。
原因不明の失敗を、再実行で通っただけで解決扱いにしない。
