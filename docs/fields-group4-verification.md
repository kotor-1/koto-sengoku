## 失敗と原因

NG の原因と、NG にはならなかったが調べて原因が分かったことを書く。

1. **城攻め前面の準備した正面攻撃（FRONT）の画面の操作（C）で、14 回目の命令（忠勝隊の門の前の持ち場への移動）が B より 2 秒遅れる（163 → 165 秒）**
   （`e2e/fields-group3-plans.mjs` の頭の記録で「突き止めていない」とあったもの。f508e95 の fields-group3-plans でも同じ数字で出た）
   - **原因（判明）：** 0 秒の 3 回目の命令（石川隊を選んで地面 (15,105) を押す）の押した点が、本多忠勝隊の点滅する名札の印（◆守護）の上だった。
     印を押すと能力をすぐ使う（直接発動。設計どおり）ので、忠勝の「退路の守護」が 0 秒に使われ、忠勝隊は踏みとどまって（待機）、1 回目の命令（(0,90) への移動）が消えた。
     石川隊は選んだまま命令は変わらない（e2e は「地面を押すと hold」と書いて移動先指定で押し直した）。
   - **確かめ：** record.json の命令の書き留め（order への書き込みを見る）に、3 回目の命令の間に「a_tadakatsu → hold」がある（ほかの 10 通りには、命令した部隊でない部隊への書き込みは無い）。
     0 秒の撮影（`e2e-out/verify-g4/fields-group3-plans/desktop-siege_front-FRONT-0s.png`）で、忠勝隊の名札が「踏みとどまる 残り 50 秒」、札が「守護 50 秒」。
     忠勝隊が (0,90) へ出ずに始めの所に残るので、出張りへ当たる所・崩した後の位置が変わり、門の前の持ち場への移動の条件を満たすのが 2 秒遅れる。D（C で入った命令の入れ直し。守護の代わりに待機を入れる）が C と同じなのは、
     守護の効き目（損害の減り）が忠勝隊が戦い始める 122 秒より前（50 秒）に切れるため。E（押した点の端数だけ替える）は B と同じなので、端数ではない。
   - **扱い：** 製品の不具合ではない（見えている印を押せば能力を使う、の決まりどおり）。e2e の地面の押しが名札の印の上を選んでいることと、
     それを「ずれ」として部隊の命令しか見ず、能力の使用に気づかないことが、e2e の側の弱さ。勝ち・主目標 ✓ は変わらない。e2e は変えていない（固定のコミットのまま）。
   - **同じことが第4群にも 1 か所：** fields-group4 の援軍救出 TOUCH（触れるだけ）の 124 秒、石川隊の地面 (60,-60) の押しで忠勝隊に待機が書き込まれ、
     240 秒の撮影で忠勝隊の札が「守護 済」（台本は守護を使わない）。TOUCH の確かめ（触れただけでは勝たない）には効かない。MAIN の作戦（EAST・DIRECT・GUARD・STEALTH・KISHI）には無い。
   - **後で直すなら（提案）：** e2e の地面の押しの前に、押す点が名札（特に点滅する印）の上でないかを見て、上なら地図を少しずらしてから押す。
     押しの後に、命令した部隊でない部隊の命令・能力の回数が変わっていないかも見て、変わればずれとして記録する。

2. **ops-group3：NG 2 件（f508e95、12:25〜12:44）「[desktop]・[phone] 移動先指定の間に酒井の名札の印を押す → 両翼の采配を使う（移動の命令にならない）」**
   - **原因（判明）：** e2e の古い期待。fdd1fa1（第4群の確かめの指摘の直し）で「移動先指定の最中は名札の印も能力にせず、その点への移動」に決まりを変えた
     （案内の帯「移動先指定中：…の行き先を押す（味方・名札の印の上も移動。能力はやめてから）」・`tests/proto3d-battle-ability-tap.test.ts`・
     `e2e/fields-group3.mjs` の conflict・`e2e/ops-group4.mjs` の B はそのとき直した）が、`e2e/ops-group3.mjs` のこの 1 か所だけ前の期待のままだった。
     製品は今の決まりどおり（NG の時の pending は none＝押しが移動として受けられた。両翼の采配は使われていない）。依頼本文 §2 の「移動先指定の素早い 2 回操作で意図しない能力発動を起こさない」に沿う変更。
   - **直し（018ea95）：** 期待を今の決まりに替えた：能力を使わない・弓隊を選んだまま・弓隊の命令が印の下の地面への移動（6 m 以内。大平原はどこも通れる）・ほかの部隊の位置と命令は変わらない。
     確かめを緩めたのではなく、決まりの変更に合わせて逆の向きの期待にした（項目の数は同じ）。

3. **fields-group2：NG 4 件（018ea95、14:28〜14:42）「[desktop]・[phone] タイトル →「合戦場の演習」→ 一覧に 15 戦場（第1群 5・第2群 5・第3群 5）」**
