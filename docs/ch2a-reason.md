# 第二章 A「織田勢の撤収を支える」：撤収のわけ（ゲーム用の創作の記録）

依頼：`docs/ch2a-reason-request.md`。第一章で勝ったのに、第二章で織田勢が撤収するわけを、短い字幕と情勢地図で分かるようにした。勝敗・兵力・支援・合戦の条件は変えていない。

## 1. 実際のシナリオで確かめた事（変えていない）

- **任務**：`chapter2/battle.ts` の `setupA`。戦場は「退却戦」の地形の写し「織田勢の退き口」。
- **合戦の説明**：「織田勢が北の陣から兵を引く。徳川は撤収を支え、織田勢の後備え・小荷駄を南の退き口まで退かせる。追ってくるのは浅井・朝倉の勢（長政は出ない）」。
- **主目標**：家康本陣と、織田勢の 2 隊（後備え 380・小荷駄 260）が、南の退き口から離脱する。
- **支援**：織田の信頼が厚ければ、織田の鉄砲隊（220）が残って加わる。
- **第一章の織田援軍（400）との関係**：援軍は、第一章で徳川と共に国境の原で戦った隊（約束の対象）。第二章 A の味方の部隊には出ない。第二章 A で守るのは、援軍とは別の隊。
- **今ある文**：近江の戦がなお続くことは、今ある文にある。探索の忠勝の「近江の戦はまだ続いております」、第二章の勝ちの結末の「近江の戦は、なお続いていく」。織田勢が「なぜ」退くのかを言う文は無かった。

## 2. 足した背景（ゲーム用の創作。史料にある出来事として言わない）

- **局地戦**：第一章の国境の原の戦（もとから「架空の局地戦」）は、局地戦にすぎない。近江の浅井・朝倉は、なお陣を構えている。
- **撤収のわけ**：近江に陣を張っていた**織田の本隊**が、その陣を引き払うと決めた。陣は情勢地図の「織田の本隊（近江の陣）」で、位置は模式。本隊は先に織田家の方へ退く。
- **追われる隊**：本隊の最後尾として最後に退く**後備え・小荷駄**を、浅井・朝倉の追っ手が追う。
- **家康が守るもの**：後備え・小荷駄の二隊が、切れ目を抜けて南の退き口から離れるまで、道を守る（主目標と同じ）。
- **この隊は織田援軍ではない**：第一章の織田援軍とは別の隊。
- **書かないこと**：特定の史実の撤退（日付・地名・人物の行い）としては書かない。信長は出さない。
