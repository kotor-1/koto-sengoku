# Version 25：会話・軍議の半身の立ち絵（人物画）と、合戦の顔を同じ原画へ

- 素材：素材パック第 2 版 `sengoku_individual_art_v2`（1 人ずつ単独に生成した 1024×1536 の人物画。受け取り・加工・出どころは docs/art-v22-structure.md の
  「Version 25 の素材の取り込み」・docs/art-assets.md・docs/third-party-assets.md）。
- この作業で変えたのは、会話・軍議・合戦の **画面の画像の出し方** だけ。物語の文・選択肢・約束・保存・合戦の計算・地形・20 戦場・第二章・音・CSP は変えていない。
  3D の人物のモデル（頭の形など）は変えていない。

## 2. 行ごとの出し方（`ui/artCanvas.ts` の `portraitStep`・`PortraitSlot`）

- 絵のある人の行：その人の絵を左下に出す（話し手が変わると 140ms で重ね変わる。動きを減らす設定では、すぐ）。
- **絵の無い話し手（使者・村の使い・知らない話し手）・地の文・高札の行は下げる。**
  Version 22〜24 は「絵の無い人物の行は前の人の絵を暗く残す」だった。速報（作業 B の全台詞の数え上げ：両章 148 の台本・1,325 の行）では、
  暗く残っていた 37 の行はすべて酒井・石川の軍議の行で、忠勝（か家康）の大きな絵が残ったまま、別の人の顔が台詞の枠に出ていた。
  Version 25 で酒井・石川にも本人の絵が付くので、その行は本人の絵になる。残る「絵の無い話し手」は使者・村の使いだけで、
  そこで前の人の絵を残すと、家康・忠勝が使者の言葉を話しているように見える。だから暗くせず下げる。
- その人の人物画が出ている行は、台詞の枠の顔を出さない（同じ人を大きな絵と小さな顔で並べない。`dialogFaceFor`。Version 22 から同じ）。
  人物画が入りきらない画面・行では、顔が台詞の枠に出る。

## 3. 大きさと置き方（`portraitLayout`・`PORTRAIT_RULES`）

- 左下に置き、下端は画面の下の端（腰から下は台詞の枠の後ろ。枠の中は透明に抜く＝台詞の字の後ろに絵が透けない）。左右の反転はしない。
- 一番大きくできる大きさ：画面の高さの 86%（高さ 430 以下は 80%）。Version 22〜24 の上限（PC 620px・スマホ横 300px）は外した。
- 重ねない物：選択肢（並びを収め直した時も測り直す）・軍議の見出し（背景が出ている間の後ろの暗さを含む）・詳しく見る・メニュー・目的の札・情勢。
  「幅で避ける」か「高さで避ける」かの大きい方までは広げる。
- **元の画像を拡大しない**：高さは「画像の高さ ÷ 端末の画素の比」まで（例：家康 1532px は、端末の比 2 で 766px、3 で 510px まで）。
  canvas は端末の比 3 まで端末の画素で描く（元の画像の画素より細かくはしない）。
- **頭・髷・肩を隠さない**：台詞の枠が人物画と横に重なるなら、枠の上端より上に、肩が見え切る所（素材ごとの `shoulderY`）まで見えていること。
  見えなければ出さない（小さくすると上端が下がって見える割合が減るので、縮めない）。`shoulderY` は `art-build.py set-anchor` で原画の画素の座標として記録し、
  加工版の割合に直して `manifest.gen.json` の meta に入る（原画の無い clone でも記録が残る）。値は人の形の幅が胸の上で最大の幅の 75% に届く行（肩の線より下）：
  家康 0.431・忠勝 0.452・酒井 0.421・石川 0.410・榊原 0.459・長政 0.397（画像の上から）。画像には髷の上に 8px の余白があり、頭の上は切らない。
- 出さない画面：高さ 340 未満（568×320 など）・左下の空きの幅 150 未満・高さ 210 未満・上の肩の決まりを満たせない。そのときは台詞の枠の顔だけ。
- 位置は absolute：出ても下がっても、遅れて読めても、台詞・名前・選択肢の位置は動かない。

## 4. 軍議の背景（`CouncilBackdrop`・`councilArtFits`）

- 昼の軍議所（1664×936。1920px 幅の要件には届かない）。**原寸以内に描ける画面だけ** 出す：
  cover で画面を埋め（上下は 18% まで切る）、元の 1 画素が端末の 1 画素以下（倍率 × 端末の比 ≦ 1）。
  それより大きく見える画面（1920×1080、768×1024、端末の比 2 の多くの画面）では読みにも行かず、Version 24 と同じ軍議の画面（3D の陣幕と暗い覆い）のまま。
  窓の大きさ・向きが変わったら決め直す（出せる大きさになれば、その時に読んで出す。超えれば外す）。引き伸ばさない。
- 出る画面の例（端末の比 1）：1280×720（倍率 0.769）・1366×768・844×390・667×375・568×320。端末の比 2 では 667×375・640×360・568×320 だけ。
- 背景は層のいちばん奥・人物画と文字の後ろ。見出しの後ろに薄い暗さ、動きを減らす設定は Version 22 と同じ。
- 画像の右に多層の天守が見える（史実の配置ではない）。PC では選択肢の並びの横・下になる。城下町・大平原の遠景の画像は使っていない（予約）。

## 6. 読み込み

- 城下で操作できるようになった時に主人公と城下の人の人物画・顔を、「話す」が出た時にその相手の分を、会話・軍議を開いた時にその台本の話し手の分を、先に読み始める。
  軍議の背景は、忠勝との会話の間と軍議の始めに、原寸以内の画面のときだけ読み始める。
- 公開する人物画は 4 枚・777,806 バイト（1 枚 182〜213KB。話さない榊原・長政の 2 枚 417,076 バイトは最後の見直しで公開から外した）。遅く読む・先に読むのは「いつ読むか」で、公開するファイルの総量は減らない。
- パックの `web/` の縮小版（768×1152）ではなく原寸を使う：768×1024 の画面・端末の比 2 では立ち絵を元の 1532px まで描く（766 CSS px）ので、1152px では 576 CSS px が拡大しない上限になる。その分、容量は web/ 版より大きい（4 枚で約 1.7 倍）。
- 読めない（失敗・時間切れ）とき：その絵は出さない（名前・台詞・選択肢・操作はそのまま。10 秒あけて読み直す）。
