## 2. 通常速度の動画（描画あり）

### 撮り方

- 道具：`e2e/story-video.mjs`
- 条件：開発サーバー・`?q=low`・描画あり（`render=manual` なし）・844×390
- CDP の画面の流しのコマを、受け取った時刻どおりに並べて、25 コマ／秒の webm にした。
- 同時に、ページの中で毎コマを記録した：演出の時計・場面・字幕・3D の出来事・カメラ・主人公・入力の時刻。
- 再生中に `page.screenshot` は使っていない。

### 確かめた環境と、確かめていない範囲

| 確かめた環境（このコンテナ） | 確かめていない範囲 |
|---|---|
| ヘッドレス Chromium（ソフトウェアの描画）・開発サーバー・`?q=low`・844×390・マウスとキー | 実機（iOS・Android・PC の GPU）での滑らかさ |
| 地図の場面：時計は実時間の 100%、毎秒約 60 コマ | 画質「高」・タッチで、通常速度の再生 |
| 3D の場面：毎秒 0.5〜1.6 コマ。時計は実時間の 40〜90% で進む。そのため導入（台本 39.5 秒）は、このコンテナでは実時間 50 秒 | 3D の場面を、通常の速さ（毎秒 30 コマ以上）で見た様子 |
| スキップ・「城下へ」の後、最初の町の画まで 3〜8 秒（町を描く重さ） | 実機での、その待ち時間 |
| 3D の場面の始めに、最初の 3D の画が出るまで 3〜6 秒。その間は字幕だけ出て、前の地図が残る | 本物のアプリの切り替え（visibilitychange）による自動の一時停止。ヘッドレスでは起きず、模擬だけ |

### 通常速度の記録から読み取った伝わり方

「誰がどこで困り、自分は何を判断するのか」が、字幕の順でどう出るかを記録から読んだ。

導入は次の順に出る。

1. 元亀元年（1570年）。三河、徳川家康の城下。
2. 近江で、織田と浅井・朝倉が敵味方に分かれた。
3. 国境で浪人の一団が村を荒らす。
4. 徳川はこれまで織田と動いてきた。
5. 織田と浅井から同じ日に使者が来る。3D で 2 人が到着し、それぞれの頼みを言う。
6. 本多忠勝が城下で待つ。
7. 軍議で道を一つ選ぶ。A・B・C は「組む相手・戦う相手」。
8. どの道でも、戦うのは国境の原。

第二章への移行（3 本）は、次の順に出る。

1. 前の章の勝敗と、約束の結果
2. 協力と敵対
3. 負傷兵（と援兵）
4. 使い（の頼み）
5. 今回の危機の場所
6. 選べる手と違い
7. 出陣の前に補充を決める

選べる手が 1 つのときは、そう言う。

「初めて遊ぶ人」の点検（コマを 1 秒ごとに見た）は、7 つの問いのどれにも「何が」の水準で答えられた。問いは、いつ・どこ・誰と誰の対立・誰の頼み・国境の出来事・選ぶこと・戦う場所。人が実機で見て分かるかは、**実機未確認**。
