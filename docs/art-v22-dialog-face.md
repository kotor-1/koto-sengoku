# Version 22：会話・軍議の台詞の枠の顔

素材パック `sengoku_art_pack_v1` の顔（256×256。`proto3d/public/art/faces/`）を、会話・軍議の台詞の枠の左に出す。
仕組みの全体は `docs/art-v22-structure.md`。

## 誰に出すか

| 話し手（台本の speaker） | 顔 | 所 |
|---|---|---|
| `hero`（歴史分岐の主人公＝家康） | `face.ieyasu` | `campaign/ieyasu1570/scenario.ts` の `ieyasuFaceOf` |
| `tadakatsu` | `face.tadakatsu` | 同上 |
| `sakai` | `face.sakai` | 同上 |
| `ishikawa` | `face.ishikawa` | 同上 |
| 使者・村の使い・高札（`notice`）・地の文（`narration`） | 出さない（左の空きだけ） | |

- 第一章・第二章で同じ。負傷している場面も同じ顔（差分の絵はまだ無い。台詞は変えない）。
- 架空の章は顔を持たない（`faceOf` を実装しない）。主人公 `hero` は宗真で、家康の顔を付けない。
- 酒井忠次・本多忠勝・榊原康政を取り違えない（それぞれ別の ID。ほかの人の顔で代用しない）。
- 榊原・浅井長政の顔は、会話・軍議の話し手にいないので使わない（合戦の顔は別の所）。織田信長・朝倉義景は画面に出る人物が無いので使わない。

## 見せ方（`ui/artCanvas.ts` の `DialogFace`・`ui/ui.css` の `.g-dialog.has-face`）

- `<canvas class="g-face" data-art-id>` を台詞の枠の先頭に置く。上下の真ん中、枠の左。PC 72px・スマホ横（高さ 430 以下）52px・縦に長い画面の幅 967px まで（タブレットの縦・小さな窓）52px・スマホの縦（幅 480px まで）44px。
  角の丸い四角（11px・スマホ 10px）、暗い半透明の地、1px の明るい縁。押せない（pointer-events: none）・読み上げない（aria-hidden）・
  ドラッグや長押しの画像の操作を出さない。左右の反転はしない。
- 画像は `art/registry.ts` の `loadArtBitmap`（fetch → createImageBitmap）だけで読む。canvas の画素は端末の比 2 まで（72px → 144 画素）。
- **左の空き**：台本のどこかの行の顔が読めたら、台本の終わりまで空きを取る（顔の無い行も空けたまま）。名前・台詞の始まりが行ごとに動かない。
  - PC：枠の右端は Version 21 のままで、左へ空きの分だけ広げる。台詞の幅・折り返し・枠の高さは Version 21 と同じ。
  - スマホ横：枠は画面の端まで使っているので、台詞の幅が空きの分（70px）だけ狭くなる。折り返しが増えて枠が高くならないよう、
    顔のある枠だけ台詞の字を 15 → 14px（字の間 0.03 → 0.01em、幅 600 以下は 0）、上下の余白を 9/11 → 6/8px にした。
  - 縦に長い画面（高さ 431px 以上）で幅の狭い所：顔 72px の空きの分だけ枠を左へ広げられるのは幅 968px 以上。幅 967px までは顔を 52px にし
    （幅 912px 以上はこれで広げきれる）、幅 911px までは顔のある枠の台詞の字を 16 → 15px・字の間 0.03 → 0.01em にする。
    スマホの縦（幅 480px まで）は顔 44px・字の間 0。
- **何も足さない（Version 21 と同じ枠）**：旧表示（`?art=old`）・素材の一覧に顔が無い・顔の無い台本（架空の章・使者だけの会話）・
  どの顔も読めない。読み込みが遅いときは、最初の顔が読めた時に空きを取る（そのとき 1 回だけ字が右へ寄る）。
  城下で操作できるようになった時・「話す」が出た時・会話と軍議を開く直前に、その話し手の顔を先に読んでおく（`ChapterGame.preloadFaces`）。
- **大きな人物画（`PortraitSlot`）と同時に出さない**：その人の人物画が出ている行は、台詞の枠の顔を下げる（左の空きは残す）。
  人物画が下がれば（狭い画面・地の文）顔を出す。今は人物画の公開版を作っていないので、人物画は出ず、顔だけが出る。

## タイトルの AI 生成の明示

素材パックの `docs/利用条件と来歴.md` と共有・公開の決まりに合わせ、タイトル（シナリオを選ぶ画面）の見出しのすぐ下に
「一部の人物・背景画像はAI生成画像を加工して使用」を 1 行、小さく出す（PC 11px・スマホ横 10.5px。スマホ横でも動かさずに見える所）。
生成イラスト素材を使っているときだけ（旧表示 `?art=old`・素材の一覧が空なら出さない）。ほかのタイトルの文は変えていない。

## 確かめ（2026-10-08・開発サーバー・本物の顔の素材）

- 台詞の枠の高さ：歴史分岐の第一章・第二章の台本の全部の行（重なりを除いて 476 行・選択肢の出る行 110 通り）を、本物の `ui.css` と字体で
  Version 21 の枠と顔の空きのある枠に入れて測った。1280×720・1920×1080・844×390・844×390（切り欠き）・667×375 では、
  1〜2 行の台詞の枠は Version 21 より高くならない（667×375 で 5 行 → 6 行が 2 つ）。568×320 は地の文 2 行だけ 2 → 3 行（+13px）。
  顔が名前・台詞・行の数・▼・選択肢と重なる所・枠が選択肢と重なる所は、どの大きさでも無い。
- 縦に長い画面（見直しの後。同じ測り方）：768×1024・800×600・900×700・940×700・960×540・1024×768 で Version 21 より高い枠は 0
  （見直しの前は 768×1024 で 95 行・800×600 で 64 行・900×700 で 20 行が高くなっていた）。スマホの縦 360×740・390×844・412×915 では、
  選択肢に重なる枠は Version 21 と同じ 48 件（新しく重なる枠は 0。見直しの前は 390×844 で 2 件増えていた）、高くなる枠は 1 行分（+22px）まで
  （360×740 で 94 行・390×844 で 65 行・412×915 で 5 行）。
- 本物の入力（クリック・タップ・キー。相手の前へは開発用の teleport、1280×720 は W キーで歩いた）での会話・軍議の流れ：`e2e/dialog-face.mjs`。
