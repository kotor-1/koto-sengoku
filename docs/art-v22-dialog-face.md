# Version 22：会話・軍議の台詞の枠の顔

素材パック `sengoku_art_pack_v1` の顔（256×256。`proto3d/public/art/faces/`）を、会話・軍議の台詞の枠の左に出す。
仕組みの全体は `docs/art-v22-structure.md`。

## 誰に出すか

| 話し手（台本の speaker） | 顔 | 所 |
|---|---|---|
| `hero`（歴史分岐の主人公＝家康） | `face.ieyasu` | `campaign/ieyasu1570/scenario.ts` の `ieyasuFaceOf` |
| `tadakatsu` | `face.tadakatsu` | 同上 |
| `sakai` | `face.sakai` | 同上 |
| `ishikawa` | `face.ishikawa` | 同上 |
| 使者・村の使い・高札（`notice`）・地の文（`narration`） | 出さない（左の空きだけ） | |

- 第一章・第二章で同じ。負傷している場面も同じ顔（差分の絵はまだ無い。台詞は変えない）。
- 架空の章は顔を持たない（`faceOf` を実装しない）。主人公 `hero` は宗真で、家康の顔を付けない。
- 酒井忠次・本多忠勝・榊原康政を取り違えない（それぞれ別の ID。ほかの人の顔で代用しない）。
- 榊原・浅井長政の顔は、会話・軍議の話し手にいないので使わない（合戦の顔は別の所）。織田信長・朝倉義景は画面に出る人物が無いので使わない。

## 見せ方（`ui/artCanvas.ts` の `DialogFace`・`ui/ui.css` の `.g-dialog.has-face`）

Version 23 で、狭い・低い画面の置き方を変えた（依頼：`docs/art-v23-request.md` の【2】「スマホの台詞は、顔追加前の 15px 未満へ縮めないでください。
狭い画面では余白、顔の寸法、配置、送り方で対応し、選択肢や本文を隠さないこと」）。

- **台詞の字はどの大きさでも Version 21 のまま**：字の大きさ（PC・縦に長い画面 16px、高さ 430 以下 15px）・字の間（0.03em）・行の高さ・
  台詞の幅・折り返し・上下の余白・枠の高さを、顔のために変えない。Version 22 の「顔のある枠だけ 14px・15px にする・字の間を詰める・
  上下の余白を減らす」は、すべてやめた。
- `<canvas class="g-face" data-art-id>` を台詞の枠の先頭に置く。角の丸い四角、暗い半透明の地、1px の明るい縁。押せない（pointer-events: none）・
  読み上げない（aria-hidden）・ドラッグや長押しの画像の操作を出さない。左右の反転はしない。
- 画像は `art/registry.ts` の `loadArtBitmap`（fetch → createImageBitmap）だけで読む。canvas の画素は端末の比 2 まで（72px → 144 画素）。
- **置き方**（`ui.css`。`DIALOG_FACE_PX`）：

  | 画面 | 顔 | 置き場所 |
  |---|---|---|
  | PC（高さ 431 以上・幅 968 以上） | 72px | 枠の左の中、上下の真ん中。枠の右端は Version 21 のままで、左へ空きの分だけ広げる（Version 22 と同じ） |
  | タブレットの縦・小さな窓（高さ 431 以上・幅 541〜967） | 52px | 枠の左上の角（下の 3 つも同じ） |
  | スマホ横（高さ 430 以下・幅 641 以上） | 44px | |
  | スマホ横（幅 640 まで）・スマホの縦（幅 540 まで） | 36px | |

  - **枠の左上の角**：枠は Version 21 と同じ位置・幅・高さ。顔の左端は台詞の始まりにそろえ、下端は名前の行の下・台詞の 1 行目の上
    （高さ 430 以下は枠の上から 25px、それ以外は 28px。Version 21 の余白＋名前の字 13px の下で、台詞の上の 4px の間の中）。
    顔は枠の上へはみ出す（44px なら 18px、36px なら 10px・縦の画面は 7px、52px なら 23px）。名前だけ顔の右へ寄せる（台詞の始まりは動かない）。
  - **選択肢などに届く行**：はみ出した顔が選択肢・軍議の見出し・詳しく見る・目的の札・メニュー・台詞に重なる行、画面の外へ出る行は、
    `DialogFace` が行ごとに測り（`faceClear`）、顔を名前の行の高さ（スマホ横 25px・それ以外 28px）に縮めて枠の中に収める（class `compact`）。
    それでも重なれば、その行は顔を出さない（`data-blocked`。空きはそのまま）。選択肢の出ている行でだけ起きる
    （568×320 の軍議の方針の行・スマホの縦の 2 行の台詞の選択肢の行で縮める。スマホの縦の軍議の方針の行は、Version 21 の枠がもう選択肢の下の端に
    重なっているので、顔を出さない）。
    **Version 24 から**：選択肢が台詞の枠・詳しく見る・メニューにかかる行は、選択肢の並びを台詞の枠の上（間 12px）へ動かす
    （`docs/v24-choices.md`）。スマホの縦の軍議の方針の行・第二章の城門と軍議の行でも、顔を 36px のまま出せるようになった。
- **顔の空き**：台本のどこかの行の顔が読めたら、台本の終わりまで空き（class `has-face`）を取る（顔の無い行も空けたまま）。名前・台詞の始まりが
  行ごとに動かない。
- **何も足さない（Version 21 と同じ枠）**：旧表示（`?art=old`）・素材の一覧に顔が無い・顔の無い台本（架空の章・使者だけの会話）・
  どの顔も読めない（読み込みの失敗でも、名前・台詞・選択肢・送りは Version 21 のまま）。読み込みが遅いときは、最初の顔が読めた時に空きを取る
  （そのとき 1 回だけ、PC は枠が左へ広がり、狭い画面は名前が右へ寄る。台詞はどちらも動かない）。
  城下で操作できるようになった時・「話す」が出た時・会話と軍議を開く直前に、その話し手の顔を先に読んでおく（`ChapterGame.preloadFaces`）。
- **大きな人物画（`PortraitSlot`）と同時に出さない**：その人の人物画が出ている行は、台詞の枠の顔を下げる（空きは残す）。
  人物画が下がれば（狭い画面・地の文）顔を出す。Version 25 から人物画（素材パック第 2 版。話す 4 人：家康・忠勝・酒井・石川）が出るので、人物画の出ている行は顔が下がり、
  入りきらない画面・行（高さ 340 未満・スマホの縦の選択肢の行など）では顔が出る（docs/v25-portraits.md）。`?art=v24` では人物画が無く、第 1 版の顔が全部の行に出る。

## タイトルの AI 生成の明示

素材パックの `docs/利用条件と来歴.md` と共有・公開の決まりに合わせ、タイトル（シナリオを選ぶ画面）の見出しのすぐ下に
「一部の人物・背景画像はAI生成画像を加工して使用」を 1 行、小さく出す（PC 11px・スマホ横 10.5px。スマホ横でも動かさずに見える所）。
生成イラスト素材を使っているときだけ（旧表示 `?art=old`・素材の一覧が空なら出さない）。ほかのタイトルの文は変えていない。

## 狭い画面の選択肢（Version 24）

詳しくは `docs/v24-choices.md`。台詞の枠の顔と字の決まりは上のまま変えない。

- **並べ方**：選択肢の並びが台詞の枠・詳しく見る・メニューにかかる、または画面の上へ出る時だけ（縦向きのスマホの軍議の方針・第二章の城門と軍議・
  第二章の補充、低い横向きの軍議・約束・補充）、並びを台詞の枠の上（間 12px）から上の部品の下（間 8px）までに収める。かからない画面は Version 23 と同じ DOM。
  `?art=old` も同じ。台詞の字（縦長 16px・高さ 430 以下 15px）・台詞の枠・顔の大きさは変えない。
- **動かし方**：収めても入りきらない時だけ、並びの中を縦に動かす（なぞり・ホイール・↑↓。ページと 3D の場面は動かない）。続きがある側の端を薄くし、
  「▲ 上にも選択肢」「▼ 下にも選択肢」の札を出す。
- **入力の守り**：並びが動く間だけ、選択肢は離した時に、ほとんど動かさずに離した押し（たたき）で決まる。なぞった・横へずらした・ブラウザが取り消した・
  動いている並びを止めた押し、押したまま上に画面（メニュー・情勢）を開いた押しでは決まらない。出たばかりの見張り（350ms）・行送りの見張り（140ms）はそのまま。
  並びが動かない時は今までどおり押した瞬間に決まる。
- **確かめ**（2026-10-09）：`e2e/dialog-face.mjs` を対応する 8 つの大きさで通し、台詞の枠が選択肢と重なる行は旧表示・顔ありとも 0
  （Version 23 の記録ではスマホの縦で 48 通り）。縦向きの軍議の方針の行でも 36px の顔が出る。並べ方と入力の確かめは `e2e/dialog-choices.mjs`。
