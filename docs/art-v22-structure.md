## 3. 画像が届いたらすること（素材パック sengoku_art_pack_v1 では 1〜4 を顔について行った。5 は利用者の評価待ち）

1. `python3 -I proto3d/tools/art-build.py ingest`
   - 断られた画像は、理由を利用者に伝えて作り直しを頼む。
2. 人物画を見て、目の高さと顔の範囲を決める（原画の画素で）。
   - `set-anchor portrait.<x> eyeY <px>`
   - `set-face-rect face.<x> X Y W H`
3. `build`
4. 画面で確かめる（通常の表示倍率）。
   - `e2e/art-compare.mjs` で、会話・軍議・大平原の前後比較を撮る。
   - 人物だけでなく、背景・地面・軍勢・UI がまとまっているかを見る。
   - 操作（送る・選ぶ・スキップ、部隊を選ぶ・動かす・能力、地図の移動・拡大縮小）を PC とスマホ横で確かめる。
5. 利用条件の確認（利用者の返事）を記録し、画面で確かめた素材を `approve` する。
6. `check --strict` → 本番ビルド → `check-dist`・`art-prod`・本番の e2e → 公開。
   - 旧表示は `?art=old` で戻せる。
   - WebP を公開先に置くのは初めて。断られたら PNG/JPEG にする。
7. 初回の比較を提出して止め、利用者の評価を待つ。

## 4. 残っている事

- **人物画・軍議の背景・地面の素材**：画面での確かめは行ったが、採用するかは利用者の判断待ち（今のビルドには入れていない）。
  入れる時は、人物画の場所（`PortraitSlot`）と台詞の枠の顔が同じ人で並ばないこと、背景の固定の人・旗・紋が保存の状態と食い違わないことを確かめる。
- **土のむら**：草地の中の土のむらが、地形のように見えないか（本物の土の素材で確かめる）。
- **林の木の数**：円の林の木は、低い画質では 7 本で、四角の林と同じ密度。本物の林床の素材と並べて見る。
- **かすかに残った背景**：画像の中ほどに不透明の背景がかすかに残っている物は、外側の帯の検査では見つからない。画面での確かめ（approve）で見る。
- **遅い端末**：地面の素材が開始のボタンまでに間に合わないことがある。そのときは今までの地面で始め、次の合戦から使う。
  顔も、ページがとても重い間（ソフトウェア描画で同時に何本もブラウザを動かした時）は 30 秒の時間切れで 1 度読めず、10 秒あけて読み直す
  （その間、その人の顔の所は空き。art-prod で見た）。
- **実機**：スマホ・タブレットの実機（iOS・Android の字体と折り返し）では確かめていない。
