## 1. 作った仕組み

| 所 | 中身 |
|---|---|
| `proto3d/src/art/ids.ts` | 素材の ID と使い道の対応（差し替え先はここ 1 か所）。人物画は登場人物の id で引く（3D の見た目の id では引かない）。顔は家康・忠勝だけで、ほかの武将には出さない |
| `proto3d/src/art/registry.ts` | 画像を読む口。fetch → createImageBitmap で読む（CSP は変えない。data: の URL・`<img>` に頼らない）。同じ ID は 1 回だけ読む。読めなければ null を返し、今までの表示のまま進む（10 秒あけて読み直す）。`?art=old` で新しい素材を一つも読まない |
| 会話・軍議（`ui/view.ts`・`ui/artCanvas.ts`・`ui/ui.css`） | 話し手の人物画を左下に出す（右向き。反転しない。選択肢・台詞・名前・ボタンに重ねない。狭い画面では出さない）。絵の無い人物（酒井・石川・使者など）の行では、前の人物画を暗くして残す。地の文の行では消す。軍議の画面には背景（と手前の幕）を出す（弱い視差・動きを減らす設定では止める）。背景が読めなければ、今までの 3D の陣幕の画のまま |
| 合戦（`battle/groundArt.ts`・`unitFx.ts`・`faceArt.ts` ほか） | 大平原の地面：草・土・道・林床の素材を、決まりの地形の形から作った型紙で混ぜる。道と林の見た目の境は、決まりの境と一致する。円の林に、今の 3D の松を植える。部隊ごとの足元の影と、短い砂ぼこり（見えている部隊だけ）。家康・忠勝の顔（部隊の札・能力の欄・発動の知らせ・演習の編成の表） |
| 受け取りと加工（`proto3d/tools/art-build.py`） | `ingest`：受け取った画像を検査し、`proto3d/assets-src/art-v22/<id>/original.png` へそのまま移す（本物の透明か。市松模様が描き込まれていないか。背景が残っていないか。マゼンタの背景は抜く）。`build`：公開版用の WebP を作る（大きさの上限つき。顔は同じ人物画から切り出す。地面は継ぎ目と焼き込まれた明暗を直す）。`check`：記録との突き合わせ |
| 公開物の確かめ（`proto3d/tools/check-dist.mjs`） | 公開の上限、`.glb` が無いこと、開発用の模様が入っていないこと |
| 前後比較（`e2e/art-compare.mjs`） | 同じ場面・同じ倍率の改修前（`?art=old`）と改修後を、PC 1280×720 とスマホ横 844×390 で撮って並べる。重なりの検査と、合戦の結果の一致の確かめも行う |
| 本番の確かめ（`e2e/art-prod.mjs`） | 本番と同じ CSP の下で、素材が読めること。素材の読み込みを止めても、文字・操作が残って進めること。`?art=old` では読まないこと |
| 開発用の TEST の模様（`proto3d/dev-art/`） | 配置と動作の確かめ用の、格子と「TEST」の文字の模様。開発サーバーで `?artFixture=1` のときだけ使う。公開版には入らない。**見た目の素材ではない** |

## 3. 画像が届いたらすること

1. `python3 -I proto3d/tools/art-build.py ingest`
   - 断られた画像は、理由を利用者に伝えて作り直しを頼む。
2. 人物画を見て、目の高さと顔の範囲を決める（原画の画素で）。
   - `set-anchor portrait.<x> eyeY <px>`
   - `set-face-rect face.<x> X Y W H`
3. `build`
4. 画面で確かめる（通常の表示倍率）。
   - `e2e/art-compare.mjs` で、会話・軍議・大平原の前後比較を撮る。
   - 人物だけでなく、背景・地面・軍勢・UI がまとまっているかを見る。
   - 操作（送る・選ぶ・スキップ、部隊を選ぶ・動かす・能力、地図の移動・拡大縮小）を PC とスマホ横で確かめる。
5. 利用条件の確認（利用者の返事）を記録し、画面で確かめた素材を `approve` する。
6. `check --strict` → 本番ビルド → `check-dist`・`art-prod`・本番の e2e → 公開。
   - 旧表示は `?art=old` で戻せる。
   - WebP を公開先に置くのは初めて。断られたら PNG/JPEG にする。
7. 初回の比較を提出して止め、利用者の評価を待つ。

## 4. 残っている小さな事（画像が届いてから見る）

- **土のむら**：草地の中の土のむらが、地形のように見えないか（本物の土の素材で確かめる）。
- **林の木の数**：円の林の木は、低い画質では 7 本で、四角の林と同じ密度。本物の林床の素材と並べて見る。
- **かすかに残った背景**：画像の中ほどに不透明の背景がかすかに残っている物は、外側の帯の検査では見つからない。画面での確かめ（approve）で見る。
- **遅い端末**：地面の素材が開始のボタンまでに間に合わないことがある。そのときは今までの地面で始め、次の合戦から使う。
