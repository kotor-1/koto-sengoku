## 2. 確かめ（種類つき）

### 本物の入力・描画あり（?q=low）・通常速度の時計（開発サーバー、e2e/story-video.mjs）
- **第一章の冒頭**：「はじめから」をクリックすると `ch1_open` が 3 場面とも 3D で流れ、地図の場面は無かった。
  - 終わると主人公は入口に北向きで立ち、W で歩けた（OK 13）。
  - 時計の終わりの確かめは、最後の場面が 3D のときの決まりに直した（269ad17）。
  - 画：scratchpad の v21/integ/video/intro-*.png。
- **第二章の冒頭**：3 つの保存（A 勝ち・約束を守った／C 負け・約束を破った・損害大／B 勝ち・約束を守った）で確かめた。OK 33・NG 0。
  - 援兵は約束を守ったときだけ出て、最後は忠勝の一言 → 入口から操作になった。
  - 町の兵の数は、演出の人数で増減しなかった。
- **入口から城門へ歩く**（e2e/town-smoke.mjs の entry。描画あり・本物の W と見回し）：第一章 OK 5・NG 0（18.7 m）。第二章も援兵あり・損害大の 2 つで確かめた（docs/story-rpg-town.md §11.4）。

### 実際に音を出力して確かめた（e2e/audio-check.mjs）
- **flow**（描画の省略 `render=manual`・実時間）
  - 冒頭（town → crisis）・城下・軍議（crisis）・合戦 ×1／×2（battle）・戦後（town）の区間で、マスターの後の RMS の平均は 0.13〜0.17 だった。
  - ミュートの間は 0、外すと戻った。
  - 2 曲が重なったのはフェードの最長 0.82 秒だけで、3 曲は重ならなかった。
  - 足音は歩いた 6 秒で 16 歩、止まった 3 秒で 0 歩だった。
  - 合戦の効果音は 1 秒に 6 までだった。
  - 声の間は BGM を下げていた。
- **interrupt**（描画の省略。隠れる操作だけはページの中で visibilitychange を起こす直接の確かめ）
  - 隠れると AudioContext が止まり、声と演出も止まった。戻っても声は読み直さず、たまった音も鳴らさなかった。
  - Esc でスキップすると声は止まり、後から読まなかった。
  - 会話の途中にタイトルへ戻ると無音になった。
- **video**（音付きの実際のプレイ映像。描画あり・実時間。scratchpad の v21/integ/audio/play-first-minute.webm、75.7 秒）
  - 画面の流し（コマと時刻）と、Web Audio の出力を MediaRecorder で取った物を、同じ実行で時刻を合わせて重ねた。コマ撮りに後から音を付けた物ではない。
  - 「はじめから」は映像の 1.5 秒ごろ。音の取り込みは 24.2 秒から入っている。取り込みを始める処理が、最初の 3D の画の組み立てで主のスレッドが空くまで待たされたためで、ゲームが無音だったわけではない。押してから最初の音までは別に 0.16 秒と測った（scratchpad の v21/audio/first-sound.json）。
  - 取り込んだ 51.5 秒の音は、途切れが 0 秒だった。
  - 声は入っていない（このコンテナに日本語の声が無いため）。
- **prod**（本番ビルド・CSP の下）：押した後の 20 秒すべてで音が出ていた。CSP の違反・ページの誤り・読めなかったファイルは 0。

## 3. 未確認・残り
- **実機での時間**：このコンテナはソフトウェア描画で、何も動かしていなくても毎秒 0.3〜0.6 コマしか描けない。そのため「はじめから」から操作開始まで実時間で 57 秒かかった（台本は 18.9 秒）。実機で 15〜20 秒に収まるかは未確認。
- **声**（実機未確認）：端末ごとの日本語の声、読みの聞こえ方、Chrome で cancel の直後に読ませた時の挙動。日本語の声が無い端末では声は出ず、字幕だけになる。
- **BGM の途切れ**：このコンテナでは、押した後に主のスレッドが最大 14 秒止まる。最初に予約する 7 秒分を越えて止まると、その間の BGM は途切れうる。実機の止まりは短い見込みだが未確認。
- **スマホのアプリの切り替え**：iOS・Android で、戻った時に音が戻るかは実機未確認。始まらないときは、次の操作で始め直す作り。
- **音の大きさの釣り合い**：耳で聞いた確かめはしていない（数値は記録済み）。
- **第二章の負傷兵 0 の保存**：使えるフィクスチャに無いため、確かめていない。
