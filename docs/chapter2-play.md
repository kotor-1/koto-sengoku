## 第一章からの続け方

第二章は、第一章の保存の**続き**として遊ぶ（タイトルに第二章の札・ボタンは無い。別のシナリオとして選び直さない）。

1. タイトルで **「歴史分岐：元亀元年・家康」の「つづきから」** を押す（説明に「章の結末」と出ている保存）。
   - 戦後（「戦の後」）の保存なら、城下で本多忠勝と話して「この章を締めくくる」と、第一章の結末の画面になる。
2. 第一章の結末の画面（今までどおり）の下に **「第二章へ進む」**（既定の選択）と「タイトルへ」が並ぶ。「第二章へ進む」を押す（PC は Enter、スマホはタップ）。
   - このとき第一章の結末を控え（`koto-sengoku/3d-ieyasu1570/chapter1`）に残してから、第二章のはじめを保存する（「保存しました：第二章の始め（自動保存）」）。
   - 保存に失敗したら「第二章の始めを保存できませんでした。第一章の保存はそのまま残っています。」→「保存せずに第二章を始める」／「結末の画面へ戻る」。
3. **「第一章の結果（第二章へ引き継ぐもの）」** の画面が 1 回出る。方針・合戦の結果・部隊ごとの兵（第一章のはじめ → 今）・約束・援兵・信頼・人物・副目標と、
   第二章で効くこと（支援・補充・敵の勢い・士気・負傷・兵が少ないとき）。「城下へ」で第二章の城下へ。
4. 以後は「つづきから」で第二章の続きになる（説明は「第二章・城下・…」「第二章・戦の後・…」「第二章の区切り・…」）。

すでに第一章を終えた保存（版 1・2・3 のどれでも）から進める。「はじめから」を選ぶと第一章から（今の保存は控え `…/previous` に残る）。

## 流れ

第一章の結果確認 → **城下**（本多忠勝・石川数正・使い・高札）→ 忠勝と話して **軍議**（今回の判断を 2 つから選び、確かめて決める。考え直せる）→
**出陣の支度**：石川数正と **補充** を決める（1 回だけ。答えるまで城門で出陣できない）→ 城門（判断・補充・出る部隊・支援をまとめて見せる）→「出陣する」（出陣前の自動保存）→
**合戦**（演習の地形を写した戦場。部隊・所属・兵・目標は物語の物）→ 結果の画面（決着の時点で戦後の自動保存）→
**戦後**の城下 → 忠勝と話して「第二章を締めくくる」→ **第二章の区切り**（9 つ。ボタンは「タイトルへ」だけ）。

### 軍議の判断（方針ごとに 2 つ）

| 方針 | 判断 1（守備隊も出す） | 判断 2（守備隊は城に残す） |
|---|---|---|
| A | 殿を引き受ける（北の丘の前で殿。織田勢は先に退く） | 退き口の手前を固める（切れ目の北の口。織田勢は北から自分で退いてくる） |
| B | 南から急いで救う | 西の筋から救う |
| C | 全軍で村を守る | 守備隊は城に残す |

- 選択肢の説明に、出る部隊（兵）・味方・始めの陣・**この判断で確定する主目標**・戦後の信頼の動き・代償を数字で出す（合戦の設定と決まりから作る）。
- 第一章の損害で、判断 2 だと本陣しか出せないときは、判断 2 を選択肢に出さず、忠勝が理由を 1 行述べる。
- 出せる兵（第一章の終わりの兵で数える）が 650 未満のときは「第一章の損害で兵が少ないため（軍議の時に出せる兵 N）、〇〇を改めた」
  （A 家康本陣を切れ目寄りから始める・B 連れ帰る兵を 3 割以上・C 屋敷前を 3 分守る）を述べる。
- **主目標は軍議で決まる**：「それで決める」を押した時に、第一章の終わりの兵を基準に、主目標の条件（兵が少ないときの調整・主目標の値・始めの陣）が
  確定する（状態の `terms`）。確かめの画面に「決めると主目標の条件が確定する：…」と出る。決める前なら「考え直す」で判断を変えられる。
  決めた後は、補充・保存・読み込み直し・出陣・戦後のどれでも、主目標の条件は求め直さない（変わらない）。

### 補充（支度で石川数正と。1 回だけ）

| 選択肢 | 中身 | 代償 |
|---|---|---|
| 負傷兵の戻りを待つ | 各部隊、第一章で失った兵（第一章のはじめの兵 − 今の兵）の 25%（石川の信頼 45 以上なら 40%）を切り捨てで戻す | 敵の後詰め・次の波が 40 秒早く着く（`CH2_RULES.waitDelaySec`。A 浅井の後詰めの騎馬 1 分 10 秒 → 30 秒・B 織田方の援軍 4 分 → 3 分 20 秒・C 波 20 秒／1 分 50 秒／3 分 20 秒 → すぐ／1 分 10 秒／2 分 40 秒） |
| 守備隊から兵を回す | 岡崎の守備隊から、足りない割合の大きい部隊へ最大 150（守備隊は 100 未満にしない。合計は変わらない） | 守備隊の兵が減る（第二章の後も減ったまま） |
| 今の兵で出る | 変えない | なし |

- 戻る兵・回す兵は選択肢の説明に部隊ごとに出る。答えた後は選べない（状態の `recovery` に選んだものと部隊ごとの増減が残る）。
- **補充では主目標は変わらない**：どの選択肢の説明にも「主目標の条件は軍議で決めたまま変わらない（…）」と出る。「待つ」の説明には、
  何が何秒に早まるか（合戦の設定を待つ・待たないで比べた時刻）が選ぶ前に出る。兵が戻って 650 を越えても、兵が少ないときの条件は外れない
  （前は補充の後の兵で求め直していたため、C で 3 分 → 6 分のように厳しくなった。直した）。新しい経済・兵站の仕組みは作っていない。
- 守備隊が 100 以下・足りない部隊が無いときは「守備隊から兵を回す」を出さず、石川が理由を述べる。失った兵がほとんど無いときは「待つ」を出さない。
- 決まりの数値は `proto3d/src/campaign/ieyasu1570/chapter2/rules.ts` の `CH2_RECOVERY` の 1 か所。

## 引き継ぎ（第一章の結果 → 第二章）

| 第一章の結果 | 第二章での効き方 |
|---|---|
| 方針 | 任務（上の表）。第二章で選び直さない |
| 部隊ごとの兵（損害） | そのまま第二章の兵。兵が 40 未満の部隊は出陣しない（家康本陣は最低 50）。戻すのは補充（代償つき）だけ |
| 援兵（約束を守った） | **第一章ですでに兵に足してある**。第二章では足さない（結果確認・石川の会話・区切りの記録に「受け取り済み」） |
| 合戦の勝敗 | 敵の兵の倍率（勝利 ×0.85・撤退 ×1.0・敗北 ×1.1）。忠勝の情勢の話・合戦の説明も変わる |
| 約束：守った／守れなかった／引き受けなかった | 相手の信頼（第一章で ±25 済み）→ 支援・士気。使者の言い方（守った＝厚い・破った＝冷たい・引き受けなかった＝違反として扱わない）。C は忠勝の話 |
| 信頼（相手の家） | A：織田 ≥ 50 で「織田の鉄砲隊」。B：浅井 ≥ 40 で「浅井の道案内」。0 未満は相手の部隊の士気 −10 |
| 信頼（石川数正・本多忠勝） | 石川 ≥ 45 で「待つ」の戻りが 40%。忠勝 ≥ 60 で忠勝隊の士気 +5、30 未満で −5 |
| 人物の負傷 | 家康：本陣の士気 −5。忠勝：忠勝隊の士気 −10（能力は使える）。長政（B）：孤立した隊は「浅井勢の後備え」（武将なし） |
| C の勝利 | 「村の衆」が自ら加わる |

第二章の信頼の動き（`chapter2/rules.ts` の `CH2_TRUST_DELTA`）：相手の家（A 織田・B 浅井）は勝利で判断 1 +15・判断 2 +10、撤退 0、敗北 −5（C は両家とも動かない）。
本多忠勝は勝利 +5。酒井忠次は勝利 +5・敗北 −5。石川数正は、岡崎の守備隊が実際に出陣した（城を空けた）とき −5。判断 1 でも、守備隊の兵が 40 未満で出なかった（補充しないと家康本陣だけで出る場合など）ときは動かない。

- 二重に適用しないもの：移る処理（純粋。もう一度押しても同じ第二章のはじめ）・補充（1 回だけ）・支援（合戦の設定を作るたびに状態から求める。兵に足さない）・戦後の処理（合戦の id ごとに 1 回）。

- 読み込んだだけでは書き換えない。2D 版・架空の章・演習の保存には触れない。壊れた保存は読み込まず、消さない。
