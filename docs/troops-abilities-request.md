# 依頼本文：合戦の大軍感と徳川武将の特殊能力の存在感（Version 13 候補）

（ユーザーの依頼をそのまま保存。これが正）

Version 12をユーザーが一通りテストプレイし、
5戦場の仕組みは問題ないと評価しました。

次は残り15戦場の量産へ進む前に、
「合戦の大軍感」と「徳川武将の特殊能力の存在感」を強化してください。

【1. 大軍感】

操作する部隊数を大量に増やすのではなく、
1部隊を複数の兵士が集まった軍勢として見せてください。

目標：
・味方6〜8部隊
・敵6〜10部隊
・1部隊あたり画面上20〜40人程度
・大きな合戦では画面全体で300〜600人程度が見える状態

内部の兵力は300・500・800などの数値で管理し、
画面上の兵士1人＝実際の兵士1人とはしません。

兵力が減ると、
部隊表示の密度や隊列が少しずつ薄くなるようにしてください。

ただしスマホ性能を優先し、
遠距離では表示人数を減らすLOD、
同じ兵士の大量描画をまとめる仕組み、
画面外部隊の描画抑制を使える構造にしてください。

部隊AIや兵力計算を兵士1人ごとには行わず、
戦闘判定は今までどおり部隊単位です。

【2. 徳川武将の特殊能力】

現在の特殊能力は方向性を維持しつつ、
「使った瞬間に戦況が変わった」と分かる強さへ調整してください。

能力はゲーム上の創作であり、
史実上の能力として説明しないでください。

徳川家康：
周囲の士気を大きく回復し、
一定時間、士気崩壊を防ぐ。
代償として家康本陣は攻勢能力を落とす。

酒井忠次：
側面・背後から攻撃している複数味方部隊の効果を
大きく引き上げる。
正面だけでは強くならず、
包囲を作ること自体が条件になる。

石川数正：
予備隊・後詰め・援軍の再配置と士気立て直しに強い。
戦線の穴を埋める能力にする。
単なる攻撃力上昇にはしない。

本多忠勝：
味方の撤退を守る能力を大幅強化する。
敵の追撃を忠勝隊へ引きつけ、
撤退中の味方の損害を大幅に軽減する。
忠勝隊自身は無敵にせず、
大きな損害を受ける危険を残す。

榊原康政：
短時間の高速移動と最初の接敵を強化し、
側面攻撃・敵弓隊への急襲・追撃に向く能力にする。

各能力は原則1合戦1回。
対象・範囲・効果・代償を画面に表示してください。

【3. 武将の役割】

能力だけでなくAIの基本方針にも差を出してください。

酒井忠次：
周囲の部隊との連携を優先。

石川数正：
予備・援軍・同盟部隊の支援を優先。

本多忠勝：
前線維持・殿軍を優先。

榊原康政：
側面・機動・追撃を優先。

武将AIが勝手に重要な作戦を決定するのではなく、
プレイヤーの命令を優先してください。

【5. 特殊能力の発動UI】

特殊能力が発動可能な武将は、
戦場上で一目で分かるようにしてください。

・能力を使える状態になった武将は、
  部隊の旗、武将名札、または足元の表示を
  控えめに点滅させてください。
・点滅は、味方の通常表示や選択状態と区別できること。
・画面全体が光る、激しく明滅するなど
  視認性を下げる演出にはしないこと。
・一時停止中でも発動可能状態が分かること。
・能力を使った後は点滅を止めること。
・戦闘不能、対象不在、使用済みなど、
  発動できない状態では点滅させないこと。

【ワンクリック発動】

対象指定が不要な能力は、
点滅している武将・部隊を1回クリック／タップするだけで
特殊能力を発動できるようにしてください。

例：
・徳川家康「立て直しの号令」
・本多忠勝「退路の守護」
・榊原康政「先駆けの号」
など、能力の対象が自隊または周囲で自動決定できるもの。

この場合、
武将を選択 → 能力ボタンを押す
という2操作を必須にしないでください。

ただし、通常の部隊選択と区別するため、
発動可能時に武将を押した場合は
能力発動を優先するか、
短い確認表示を出す設計にしてください。
誤操作が多くなる場合は、
「能力発動状態の点滅中のみワンクリック」を条件にしてください。

【対象指定が必要な能力】

対象部隊を選ぶ必要がある能力は、
ワンクリックで勝手な対象へ発動しないでください。

例：
・浅井長政「盟友への援護」
・石川数正の再配置・支援など、
  対象を選ぶ意味がある能力。

この場合は、
1. 点滅している武将をクリック／タップ
2. 発動対象をクリック／タップ
3. 発動
の流れにしてください。

対象選択中は、
選べる部隊を分かりやすく表示してください。
不適切な対象を押しても使用回数を消費しないこと。

【スマホ操作】

スマホでは、
能力ボタンを探して小さなUIを押すよりも、
戦場上の武将を直接タップして発動できることを優先してください。

点滅している武将のタップ判定は、
見た目の人物サイズより少し広めにしてください。
ただし隣の部隊を誤って押すほど広くしないでください。

通常の移動・攻撃・部隊選択と競合しないこと。
同じ指のタップが、
能力発動後に地面への移動命令まで通らないようにしてください。

【発動時のフィードバック】

能力を発動したら、
・能力名
・発動した武将
・対象
を短時間表示してください。

長いカットインや動画演出は不要です。

武将の旗や部隊の周囲に、
短い光・波紋・色の変化などを出し、
「能力が発動した」と分かる程度にしてください。

発動後、
効果時間がある能力は残り時間を確認できること。
効果終了時も、短く分かる表示を出してください。

【確認】

次を実際のPC・スマホ相当操作で確認してください。

・能力使用可能な武将だけが点滅する。
・対象不要能力は1クリック／1タップで発動できる。
・対象指定能力は武将→対象の2段階で発動できる。
・使用後は点滅が消える。
・戦闘不能や使用済みでは点滅しない。
・指揮停止中に点滅や発動状態が壊れない。
・連打しても2回発動しない。
・能力を発動したタップが、移動命令や別の部隊選択に漏れない。
・既存のPC操作とスマホ操作を壊さない。
