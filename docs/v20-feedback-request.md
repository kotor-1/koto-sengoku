# 依頼（Version 20 の試遊の後）：冒頭・城下町の導線・ボイス・BGM と効果音（原文）

ユーザーがVersion 20を試遊しました。

評価：
・冒頭から図解が始まり、離脱しそうになった。
・その後のキャラクターが出る場面はよい。
・城下町ができているのか、遊んでも分かりにくい。
・ボイスとBGMが欲しい。

次はこの4点を改善してください。
合戦、20戦場、第一章・第二章の選択と結果は維持します。
最新の作業状態を確認し、既存成果を引き継いでください。

【1. 冒頭を人物と町から始める】

第一章の開始直後に、情勢地図を自動再生しないでください。

既存の町の3D場面と使者の到着を活用し、
町の様子 → 急報 → 主人公と家臣の短いやり取り
→ プレイヤー操作、という順にします。

ロード完了後15〜20秒程度で操作開始できることを初期目安にします。
長いナレーションや、図解を別の形で読み上げる導入にはしません。

時代、主人公、目前の目的は短い字幕で分かるようにする。
会話と出来事は現在のシナリオに合わせ、
新しい史実や事件を無根拠に足さないこと。

第二章も、前章の結果に合った人物・町の場面から始めます。
既に評価されたキャラクターの場面は、できるだけ再利用します。

情勢地図は削除せず、
軍議の「詳しく見る」や情勢画面から任意に確認する補助にします。
図解の視聴を進行条件にしないでください。

【2. 城下町の存在が分かる導線】

報告済みの木戸、荷の通り、詰所、軍議所、町人が、
現在の公開版でどこにあり、開始位置からどう見えるか確認してください。

開始位置から軍議へ向かう途中で、
町の通りと、働く町人や出陣準備が自然に見える配置にします。
建物やNPCを追加するだけでなく、
実際に歩く道とカメラから見えることを確認してください。

既存素材の配置と案内を優先します。
配置を変える場合は、当たり判定やNPCの経路も合わせて更新します。

負傷兵・援兵の出し分けは現在の保存状態と一致させます。
町の表示によって、兵力や支援を再加算しないでください。

町人全員への会話や物見を、出陣条件にしません。
顔・衣服・建物の高精細化には戻らないでください。

【3. ボイス】

まず冒頭の使者、主要人物の短い返答、
出陣・撤退・能力発動など、短い重要台詞を音声化します。
全会話の読み上げや口パクは今回は不要です。

無料の音声合成で事前生成した音声を使う方式を第一候補にします。
候補はVOICEVOX Nemoです。
利用規約と必要なクレジットを確認し、
音声エンジンや巨大なモデルをゲームへ同梱せず、
生成した必要な音声だけを使ってください。

制作環境で利用できない場合は、
端末の日本語読み上げを暫定候補として試してください。
端末依存であること、日本語音声がない場合は音声なしになることを明記します。
取得失敗の再試行を繰り返して全工程を止めないでください。

字幕と音声の内容を一致させ、
家康・忠勝・数正などの読みを確認してください。
表示用の漢字と、音声用の読みは分けて管理して構いません。

台詞を送る・スキップする・別場面へ移ると、
古い音声を止め、後からまとめて再生しないこと。
複数人物が同時に話さないようにしてください。
特定の俳優や他作品の声を模倣しません。

【4. BGM・環境音・効果音】

購入・外注・有料APIは使いません。
BGMと効果音は、オリジナルとして制作してください。
既存ゲームやドラマの曲・録音を流用しません。

BGMはまず3種類：
・城下町
・危機／軍議
・合戦

短い単音を繰り返すだけではなく、
旋律・伴奏・打楽器に変化のあるループを作ってください。
和風を意識しますが、電子音の警告音ばかりにならないようにします。

環境音は足音、木戸、荷の作業音、風などから必要最小限。
足音は実際の歩行・走行に合わせ、停止中は鳴らさないこと。
合戦の効果音は兵士全員分を同時に鳴らさず、発音数を制限します。

曲の切り替えは短いフェードで行い、
ボイス中はBGMを下げて台詞を聞き取りやすくします。
出陣と帰還で、曲や環境音が適切に切り替わること。

【5. 音の開始・設定・中断】

開始ボタンなどのユーザー操作で音を有効にする。
音を出すためだけに、長い別の設定画面を追加しないでください。

全体ミュートと、
BGM・ボイス・効果音／環境音の音量を調整・保存できること。

音声の許可や読み込みに失敗しても、ゲーム進行を止めないこと。
字幕は残し、無音でも必要な情報が分かるようにする。

アプリ切り替えでは音を停止または一時停止する。
復帰時に重複再生や、たまった掛け声の連続再生をしないこと。
カットシーンの一時停止・スキップとも整合させてください。

通常のBGMや音声の再生時計を、
描画フレームの遅さに比例させないでください。
合戦の倍速で声の高さまで変えないこと。

【6. 容量と配信】

音を追加する前に、現在の公開容量と音声ファイルの配信可否を確認する。
巨大な音源集や生成エンジンを同梱しないこと。

必要なら圧縮音声や軽量なWeb Audio合成を使用します。
遅延読み込みだけで公開先の総容量が減るとは扱わないでください。
既存モデルの読み込み修正を壊さず、セキュリティ設定も緩めません。

【7. 完成確認】

・冒頭が図解ではなく、人物と町の出来事から始まる。
・短い導入の後、町を自分で歩いて軍議へ向かえる。
・地図を見なくても、目前の目的は分かる。
・主要な短い台詞が聞こえ、BGMと生活音が鳴る。
・音量調整、ミュート、中断、スキップで音が重複しない。
・無音や音声読み込み失敗でも、進行・保存が正常。
・既存の合戦条件と結果が変わっていない。

音声APIの呼び出し成功だけを「音が出た」確認にしないでください。
実際に音を出力して確認した内容と、
自動テストだけの内容、実機未確認を分けて報告します。

最初の1分程度について、可能なら音付きの実際のプレイ映像を添えてください。
コマ撮り映像に後から音を付けたものを、
リアルタイム動作の確認として扱わないでください。

必要な確認後、旧版と保存を保護して確認URLへ反映し、
公開版、導入の変更、城下町への行き方、
音の種類と操作、未確認事項を短く報告してください。
