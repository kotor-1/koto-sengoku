今回で、演習として選んで遊べる戦場を最低20種類にします。

現在さらに作業が進んでいれば、その成果を確認して引き継いでください。

【1. 未解決の味方同士の詰まり：仕様を決定します】

「待機中の味方に12秒塞がれてから通過する」は変更します。
テストの許容時間だけを延ばして解決扱いにしないでください。

短い通行可能な迂回があれば優先します。
味方だけに塞がれた状態が2秒続いたら、
味方同士の通過を調整する処理を開始してください。
2秒は調整可能な初期値として一か所に定義します。

既存の味方限定すり抜け処理を使う場合も、
壁、閉じた門、深い川、敵部隊には適用しないこと。
防衛・待機を命じられた味方を勝手に移動させないこと。
狭路で同時に交戦できる部隊数の制限は維持すること。

既存の村落の再現ケースで、
長時間停止せず目的地へ進めることを確認してください。
物理的に経路が存在しない場合は、理由を表示し、
無理に通過させないでください。

【2. 操作と配置の残件】

・能力説明パネルへのタップやスクロールを、
  下の戦場への移動・攻撃命令に通さない。
  操作不要の通知の透過処理と区別する。

・移動先指定の素早い2回操作で、
  意図しない部隊の選び直しや能力発動を起こさない。

・閉じた門の先へ出した移動命令は、
  目的地と「開門待ち」の状態を保持する。
  開門後に再経路計算して続行する。
  プレイヤーが新しい命令を出したら、古い保留命令は破棄する。
  敵への攻撃可否や射線判定とは混同しない。

・城下町外縁の味方退き口と敵突破口を分離し、
  地図と説明でも用途を区別する。

・上部の通知で重要な名札が隠れる場合は、
  折り畳みや配置変更で、選択と能力発動を妨げないようにする。

【3. 最後の5戦場】

16. 包囲された陣
主目標：総大将と指定数の部隊が、包囲の外へ脱出する。

中央付近から開始し、複数の方向に敵を配置する。
短いが守りの厚い突破口と、
回り道になるが手薄な突破口を用意する。
総大将を逃がす前に、突破路を開く判断が必要な構成にする。

総大将が指定の出口へ脱出したことを、
通常戦の本陣喪失による敗北と誤判定しないこと。

17. 援軍救出
主目標：孤立した味方と合流し、安全地点まで退かせる。

合流地点と安全地点を分ける。
接触だけ、能力使用だけでは救出成功にしない。
対象の生存条件や最低残存兵力は出陣前に表示する。

急いで直接救援する作戦と、
敵の一部を引き離してから救援する作戦を成立させる。
救出対象と増援も、同時存在する部隊数の上限に含める。

18. 退却戦
主目標：総大将と必要な部隊を退き口から離脱させる。

敵が実際に追撃し、殿軍と撤退順に意味を持たせる。
本多忠勝の守護を使う価値がある状況を作るが、
能力使用を勝利の必須条件にはしない。

目標どおり退却できた場合は、この戦場では勝利とする。
通常戦の全軍撤退処理で、目標達成前に即終了しないこと。
単なる合戦放棄と、目標を達成した撤収を区別して説明する。

19. 夜襲・奇襲
主目標：夜間に指定の敵拠点を制圧する。

敵味方の視界と発見状態を使い、
未発見の敵の名札や位置情報を表示しない。
敵側も未発見の味方の位置を当然に知って攻撃しない。

近いが警戒の厚い経路と、
長いが見つかりにくい経路を用意する。
隠れて近づく方法だけでなく、
発見後に戦って目標を取る可能性も残す。

画面を暗くしただけの既存戦場にはしない。
複雑な照明演出や新しい美術制作は不要。

20. 湖・河岸
主目標：補給路上の二つの要所を一定時間維持する。

一方向を水面で制限し、
狭い岸沿いの道と、内陸側の迂回路・高地を作る。
近道の確保と、内陸からの側面攻撃への対応を両立させる。

船、海戦、乗船システムは今回は追加しない。
水辺を利用した陸戦として完成させる。

【4. 共通の完成条件】

5戦場は、それぞれ地形・初期配置・経路・主目標を設計する。
同じマップの名前と目標文だけを変えたものは数に含めない。

既存の目標システムを拡張し、
突破・救出・撤収などの達成と、
通常の本陣喪失・日没・全軍撤退が競合しないようにする。
戦場ごとの終了条件と判定の優先順位を明示する。

主目標、副目標、約束、勝敗を別々に記録する。
演習の結果を歴史シナリオの信頼や兵力へ勝手に加算しない。

大軍表示、LOD、武将の能力、点滅と直接発動、
命令の優先順位、保存と二重適用防止を維持する。

正面攻撃を一律に負けにしない。
複数の作戦で、時間・損害・守れる部隊・副目標に違いを出す。

【5. 確認と公開】

20戦場すべてが、タイトルの一覧から通常操作で開始できること。

新しい5戦場は、それぞれ少なくとも1経路を
本物のクリック・タップによる命令で主目標まで通すこと。
別作戦との比較には台本も使ってよいが、
通常入力、早送り、直接状態変更、実機確認を区別して報告する。

特に次を確認する。
・総大将の脱出が誤って敗北にならない。
・救出対象に接触しただけで勝利しない。
・退却戦で敵が追撃し、撤退支援が実際に作用する。
・夜襲で未発見部隊の情報が漏れない。
・味方の詰まりと、説明パネルからの誤命令が再発しない。

変更の影響を調べ、必要な既存機能の回帰確認を行う。
固定したビルドと検証記録を対応させ、
再起動後は未完了・変更の影響がある項目から再開する。
再実行で通っただけの原因不明の失敗は、解決扱いにしない。

旧版と既存セーブを保護して確認用URLへ反映する。
公開先の実際の版番号とコミットを報告する。

今回は顔・衣服・町の美術、全国マップ、
大量の武将追加、エンジン変更には進まない。

完了報告は、
20戦場の一覧、追加5戦場の特徴、
修正結果、確認済み経路、未確認事項に絞る。
